# 인증정보마다 키움 실시간 연결은 하나이고, 모든 실시간 기능이 공유한다

같은 앱 키로 실시간 연결을 하나 더 열면 키움이 앞 연결에 `SYSTEM` 코드 `R10001`을 보내고 끊는다(2026-10 모의 서버에서 확인). 그래서 체결 알림, SL / TP처럼 실시간 항목이 필요한 기능은 각자 연결을 열지 않고, 인증정보마다 하나씩 여는 공유 실시간 연결에 구독을 등록해 이벤트를 받는다. 다시 연결하면 공유 연결이 모든 구독을 다시 등록하고, `R10001`을 받으면 그 연결을 쓰는 모든 기능이 함께 멈춘다.

## Consequences

- 국내 실전과 미국 실전은 인증정보가 같아 연결 하나를 함께 쓴다. 국내 모의와 미국 모의는 따로다.
- 실시간 연결은 Discord 알림 설정과 상관없이, 구독이 하나라도 있는 투자 환경에만 연다.
- 같은 앱 키로 서버를 둘 띄우면 서로를 끊어내므로, 나중에 연결한 쪽만 남고 먼저 연결한 서버의 실시간 기능은 모두 멈춘다.
