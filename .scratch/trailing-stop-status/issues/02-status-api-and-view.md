# 02: 상태 조회 API와 Trailing Stop 보기 (감시 없음)

**What to build:** 계좌 확인의 보유종목 목록 위에 [기본 | Trailing Stop] 보기 전환이 생긴다. Trailing Stop 보기에서는 각 보유종목의 수익률(계좌 현재가 기준), 활성화 수익률 도달 여부, 제외종목 여부, Trailing Stop 상태를 보인다. 이 티켓에서는 아직 시세를 감시하지 않으므로, 제외종목이 아닌 종목의 상태는 모두 "감시 안 함"과 그 이유다. 실전 환경에서 화면 전체를 확인할 수 있다.

Spec: `.scratch/trailing-stop-status/spec.md` (자체 서버 API, 화면, 로그)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] `GET /api/environments/{environment}/trailing-stop/status`가 spec의 응답 모양으로 답한다. 키움을 부르지 않는다. 로그인 세션이 필요하고, 잘못된 환경 값은 기존 규칙대로 거부한다.
- [ ] `session`은 지금 시각을 포함하는 Trailing Stop 세션이다. 꺼진 세션이어도 담고, 없으면 `null`이다. `excluded`는 Trailing Stop 제외종목 코드다.
- [ ] 이 티켓에서는 `watching=false`이고 `stocks=[]`이다. `not_watching_reason`은 실전이면 `real`, 인증정보가 없으면 `no_credentials`, 자동매매 설정 파일을 읽지 못하면 `settings_unreadable`, 그 밖에는 `no_session`이다.
- [ ] 화면: 보기 전환이 국내·미국 계좌에 모두 있고, 고른 보기를 브라우저에 기억한다. 저장소를 쓸 수 없으면 기본 보기다. 기본 보기의 겉모습과 동작은 바뀌지 않는다.
- [ ] 화면: 수익률은 계좌 응답의 현재가와 평균 매입가로 계산하고(수수료·세금 제외), 기존 부호·색 규칙을 따른다. 미국은 기존 외화 표기를 따른다.
- [ ] 계좌 API(국내·미국)의 보유종목 줄에 신용 보유분인지(`credit`)를 더한다. 미국은 늘 `false`다. 기존 칸은 바뀌지 않는다.
- [ ] 화면: 도달 여부는 "미도달 (기준 5%)", "도달 (세션 밖)", "—" 가운데 하나다. 제외종목 여부를 따로 보인다. 상태는 spec의 우선순위대로 정한다. 실전 환경은 제외종목을 포함해 모두 "감시 안 함 · 실전투자"이고, 모의 환경은 "제외종목", 신용 줄은 "대상 아님 · 신용", 그 밖에는 "감시 안 함 · <이유>"이다.
- [ ] 화면: 계산할 수 없는 값은 "—"로 보인다. 평균 매입가나 가격이 없거나 0이면 수익률과 도달 여부가, 지금 세션에 활성화 수익률이 없으면 도달 여부가 그렇다.
- [ ] 화면: 목록 위에 수수료·세금과 고점 기준 안내를 둔다. 매도 버튼, 거래소 확인 불가 안내, 매도 가능 수량 표시는 Trailing Stop 보기에서도 그대로다.
- [ ] 화면: Trailing Stop 보기가 열려 있고 탭이 보이는 동안 3초마다 상태를 다시 받는다. 처음 열 때와 탭이 다시 보일 때는 바로 받는다. 실패하면 마지막 값을 두고 실패 안내를 보이며, 한 번도 받지 못했으면 상태 칸을 "—"로 둔다.
- [ ] 상태 조회 로그는 실패만 INFO 이상으로 남긴다.
- [ ] 테스트(pytest): 네 환경의 `not_watching_reason`, 지금 시각을 포함하는 세션(꺼진 세션 포함, 경계 시각, 없음), 제외종목, 로그인 없는 요청 거부, 키움 요청이 하나도 없음, 계좌 응답의 `credit`(현금·신용 같은 코드 두 줄)을 확인한다.
- [ ] 테스트(Playwright): 보기 전환과 새로고침 뒤 유지, 수익률·도달 여부 세 가지·제외종목·감시 안 함 표시, 실전 환경의 제외종목도 감시 안 함 · 실전투자, 신용 줄의 대상 아님, 기준·매입가·가격이 비거나 0일 때 "—", 3초 갱신과 탭이 숨으면 멈춤, 조회 실패 안내, 국내·미국 표기, 모바일 폭에서 잘리지 않음을 확인한다. 기존 계좌 화면 e2e가 모두 통과한다.
- [ ] 기존 테스트, lint, 타입 검사, 화면 빌드가 모두 통과한다.
