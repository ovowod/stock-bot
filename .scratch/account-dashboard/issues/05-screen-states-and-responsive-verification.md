# 05: 화면 상태와 반응형 최종 확인

**What to build:** 실전 환경 표시, 모든 화면 상태, 응답이 늦을 때의 환경 전환이 데스크톱과 모바일 화면에서 의도대로 보이는 것을 브라우저로 확인하고, 빌드와 개발 모드 실행 방법까지 정리한다.

Spec: `.scratch/account-dashboard/spec.md`

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] Playwright로 브라우저의 `/api` 요청을 가로채 가짜 응답을 주고, 운영 코드에는 테스트용 분기를 넣지 않는다.
- [ ] 실전 환경(국내·미국) 화면을 가짜 응답으로 확인한다. 실전 서버는 호출하지 않는다.
- [ ] 불러오는 중, 새로고침 중, 오류별 화면, 보유종목 없음, 정상 상태를 확인한다.
- [ ] 응답을 늦춘 상태에서 투자 환경을 바꾸면 이전 환경 데이터가 즉시 사라지고 늦은 응답이 반영되지 않는 것을 확인한다.
- [ ] 마지막 투자 환경 기억과 잘못된 저장 값의 국내 모의 대체를 확인한다.
- [ ] 데스크톱(1440px)과 모바일(390px) 스크린샷으로 레이아웃, 메뉴 서랍, 한 줄 4칸 환경 버튼, 표 영역, 가로 밀림 없음을 확인한다.
- [ ] 국내 모의와 미국 모의를 실제 서버로 한 번 더 확인한다.
- [ ] 서버 테스트, 화면 빌드(타입 검사 포함)를 실행해 통과를 확인한다.
- [ ] 개발 모드 실행 방법을 사용자에게 안내한다.
