# 03: 미국 계좌 확인

**What to build:** 미국 모의(또는 미국 실전)를 고르면 계좌 확인 화면에 USD 기준 자산 요약과 KRW 환산값, 원화·통화별 외화예수금, 미국 보유종목이 표시된다. 국내 계좌 확인과 같은 흐름(계좌번호 비교 → 잔고·예수금 조회)과 같은 화면 상태를 쓴다.

Spec: `.scratch/account-dashboard/spec.md`

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 미국 투자 환경에서 `ka00001` 계좌번호 비교 후 `ust21070`(`stex_tp=""`, `stk_cd=""`)과 `ust21110`을 호출한다.
- [ ] USD 소수 문자열과 0으로 채운 KRW 문자열을 각각 숫자로 바꾸고, 문서에 없는 최상위 `stex_tp`는 쓰지 않는다.
- [ ] API 응답이 시장 필드로 국내 결과와 구분되며, USD 요약(총평가금액, 총매입금액, 총평가손익, 수익률, 당일손익), KRW 환산 요약, 원화예수금, 통화별 외화예수금(외화예수금, 외화주문가능금액), 보유종목을 담는다.
- [ ] 보유종목 표에 티커, 종목명, 거래소명(`result_list.stex_nm` 값 그대로), 보유수량, 매도가능수량, 매입단가, 현재가, 평가금액, 평가손익, 수익률이 보인다. 응답에 없는 보유비중은 표시하지 않는다.
- [ ] USD와 KRW 금액이 각각의 통화 표기로 구분되어 보이고, 손익 색상 규칙은 국내와 같다.
- [ ] 가짜 응답 테스트가 통과한다: 미국 응답 변환, 빈 보유종목, 미국 실전과 국내 실전이 같은 `REAL_*`를 쓰는지.
- [ ] 미국 모의 서버로 실제 조회해 확인한다. `ka00001`이 미국 모의 인증정보로 동작하지 않으면 구현을 멈추고 사용자에게 보고한다. `stex_nm`에 실제로 오는 값을 보고한다.
