# 01: 앱 골격과 투자 환경 선택

**What to build:** 개발 모드로 띄우면 참고 화면 구조의 대시보드가 열린다. 상단에 투자 환경 버튼 4개(국내 실전·미국 실전·국내 모의·미국 모의)가 있고, 처음에는 국내 모의가 선택되며 이후에는 마지막으로 고른 투자 환경으로 열린다. 실전 환경을 고르면 경고 색과 "실전" 배지가 보인다. 왼쪽 메뉴에는 계좌 확인 하나가 선택된 상태로 있고, 오른쪽에는 계좌 확인 화면 자리(내용 없음)가 보인다. 모바일에서는 햄버거 버튼으로 메뉴 서랍을 열고, 투자 환경 버튼은 헤더 아래 한 줄 4칸으로 놓인다. 서버는 투자 환경 목록 API를 제공하고, 설정과 로그의 기반을 갖춘다. 빌드한 화면은 서버가 직접 제공한다.

Spec: `.scratch/account-dashboard/spec.md`

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 서버(FastAPI, 기존 uv 프로젝트)와 화면(React·Vite·TypeScript·Tailwind, lucide 아이콘)이 개발 모드에서 함께 뜨고, 화면의 `/api` 요청이 서버로 전달된다.
- [ ] `GET /api/environments`가 투자 환경 4개(값, 표시 이름, 시장, 실전 여부)를 돌려주고, 인증정보는 담지 않는다.
- [ ] 투자 환경 값은 정해진 4개만 허용하며, 그 밖의 값을 쓰는 서버 경로는 공통 오류 형식(오류 종류, 사용자용 메시지, 요청 ID)으로 404를 돌려준다.
- [ ] 프로젝트 최상위 `.env`의 절대경로를 코드 위치로 계산해 파일이 있을 때만 읽고, 이미 설정된 환경변수를 덮어쓰지 않는다.
- [ ] 로그가 stdout과 `logs/` 양쪽에 구조화된 한 줄 형식(시각, 레벨, 모듈, 투자 환경, 요청 ID 등)으로 남고, 파일은 날짜별로 나뉘어 14일 보관된다.
- [ ] 마지막 투자 환경이 localStorage에 저장되고, 저장 값이 없거나 잘못되었거나 저장소 접근이 실패하면 국내 모의로 연다.
- [ ] 실전 환경 선택 시 헤더에 경고 색과 "실전" 배지가 보인다.
- [ ] 메뉴는 기능 목록 데이터로 만들어져 항목 하나만 추가하면 기능이 늘어난다.
- [ ] 데스크톱에서는 왼쪽 고정 메뉴, 모바일에서는 메뉴 서랍과 한 줄 4칸 환경 버튼이 동작하고 화면 전체가 가로로 밀리지 않는다.
- [ ] 화면 빌드 결과물을 서버가 직접 제공한다.
- [ ] pytest가 설정되어 있고, 환경 목록 API, 잘못된 환경 값 거부, `.env` 로딩 우선순위를 검증하는 테스트가 통과한다(실제 `.env`는 읽지 않음).
