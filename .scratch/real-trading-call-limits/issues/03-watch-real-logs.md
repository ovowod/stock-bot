# 03: 실전 화면 사용 중 로그 확인

**What to build:** 실전투자 화면을 평소처럼 쓰면서 로그에 호출 한도 오류가 남는지 본다. 실전 서버에 일부러 요청을 몰아 보내지 않고, 실전 주문은 보내지 않는다. 결과에 따라 한도나 단위를 바꿀지 결정을 받는다.

Spec: `.scratch/real-trading-call-limits/spec.md` (Further Notes)

**Blocked by:** 01, 02

**Status:** ready-for-human

- [ ] 실전 조회 화면만 쓴다(계좌 확인, 순위, 종목 검색, 현재가). 주문·취소는 보내지 않는다.
- [ ] 국내 실전과 미국 실전 순위 화면을 열고 조건을 바꿔, 카드 4개가 함께 채워지고 `1700`/`1701`/`1702`가 없는지 본다.
- [ ] 가능하면 한국시간 오전 9~10시에 미국 실전 화면을 써 보고, `peak=true` 대기 로그와 한도 오류 여부를 본다.
- [ ] 확인 기간 로그에서 `1700`/`1701`/`1702`를 검색해, 남은 경우의 TR·`pacing_unit`·시각을 기록한다. 모의 화면에서도 1.2초 기준으로 `1700`이 사라졌는지 본다.
- [ ] 미국 종목 목록(`usa10099`)이 실패한 뒤 검색을 반복해 `1700`이 나는지 본다.
- [ ] 결과를 spec에 Implementation Notes로 날짜와 함께 기록하고, 한도를 줄이거나, 국내·미국 단위를 합치거나, 응답 시각부터 세는 방식으로 바꿀지 결정한다.
