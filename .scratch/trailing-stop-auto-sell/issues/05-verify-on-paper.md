# 05: 모의투자에서 Trailing Stop 자동 매도 확인

**What to build:** 국내 모의와 미국 모의에서 실제 Trailing Stop 자동 매도가 동작하는지 사용자가 직접 확인한다. 테스트의 가짜 응답으로는 알 수 없는 키움 서버의 동작을 확인한다.

Spec: `.scratch/trailing-stop-auto-sell/spec.md` (Further Notes)

**Blocked by:** 01, 02, 03, 04

**Status:** ready-for-human

- [ ] 활성화 수익률과 고점 대비 하락률을 작게 잡은 세션으로 국내 모의 종목이 트리거되고, 자동 매도가 접수되며, "Trailing Stop 자동 매도 접수" 알림이 온다.
- [ ] 그 체결 알림에 "Trailing Stop 자동 매도"가 붙는다(주문 응답과 체결 이벤트의 주문번호 형식이 같은지).
- [ ] 미국 모의에서 같은 확인을 한다(거래소, 주문번호).
- [ ] 계좌 확인의 Trailing Stop 보기에서 자동 매도 값이 보내는 중 → 접수로 바뀌고, 전량 체결 뒤 계좌를 새로고침하면 종목이 목록에서 빠진다.
- [ ] 같은 종목을 SL / TP와 Trailing Stop 세션에 함께 두었을 때, 시세 실시간 등록이 거부되지 않고 두 기능 모두 시세를 받는다. 200종목 한도를 서로 다른 종목 수로 세는지 그룹별 합으로 세는지는 이 확인으로 알 수 없으므로 미확인으로 적는다.
- [ ] 실전투자 환경에서 Trailing Stop 보기가 감시 안 함 · 실전투자이고, 로그에 주문 TR이 없다.
- [ ] 확인 결과와 로그 요약을 이 파일 Comments에 적는다.
