# 01: SL / TP 메뉴와 제외종목 저장

**What to build:** 왼쪽 메뉴에 "자동매매" 묶음과 "SL / TP" 메뉴가 생긴다. 화면을 열면 선택한 투자 환경의 SL / TP 설정을 서버에서 불러오고, 매도 방식 안내와 준비 중 안내를 보여준다. 맨 위에서 기존 종목 검색으로 제외종목을 찾아 추가·삭제하고, "저장"을 누르면 서버가 그 환경의 JSON 파일에 저장해 서버를 다시 시작해도 남는다. 이 티켓에서 SL/TP 세션 목록은 늘 비어 있다(편집은 02에서).

Spec: `.scratch/sl-tp/spec.md` (설정 모듈, 검사 규칙의 제외종목, 자체 서버 API, 로그, 화면)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 데스크톱 메뉴와 모바일 서랍에 "자동매매" 묶음 아래 "SL / TP"가 보이고, 투자 환경을 key로 묶어 환경을 바꾸면 새로 불러온다.
- [x] `GET /api/environments/{environment}/sl-tp`가 `environment`, `market`, `timezone`, `regular_hours`, `can_enable`(실전 false), `updated_at`, `excluded`, `sessions`를 돌려준다. 키움을 부르지 않는다.
- [x] `PUT /api/environments/{environment}/sl-tp`가 `excluded`, `sessions`를 받아 검사한 뒤 저장하고 GET과 같은 응답을 돌려준다. 이 티켓에서 `sessions`는 빈 목록만 받고, 그 밖은 400이다.
- [x] 저장 위치는 `data/sl-tp/<환경 값>.json`이고 `data/`는 git에서 제외한다. 앱을 만들 때 저장 폴더를 넘길 수 있고 테스트는 임시 폴더를 쓴다. 파일에는 `version: 1`이 들어간다.
- [x] 파일이 없으면 빈 설정(`updated_at=null`)이다. 파일이 깨졌거나 형식·규칙에 맞지 않으면 GET은 500 `sl_tp_settings_unreadable`이고 파일을 바꾸지 않는다.
- [x] 쓰기는 임시 파일에 쓴 뒤 바꿔치기하고, 같은 환경의 저장은 한 번에 하나씩 처리한다. 쓰기 실패는 500 `sl_tp_settings_write_failed`이고 기존 파일은 그대로다.
- [x] 제외종목 검사: 같은 `code` 두 번, 빈 코드·이름, 국내에 거래소 값, 미국에 `NYSE`·`NASDAQ`·`AMEX` 밖의 거래소는 400 `invalid_sl_tp_settings`이고 메시지에 위치를 담는다.
- [x] 네 환경의 설정이 각각의 파일에 저장되고 서로 덮어쓰지 않는다.
- [x] GET·PUT 모두 로그인 세션 없는 요청은 401, 잘못된 환경 값은 기존 규칙대로 거부되고, 설정 파일이 생기거나 바뀌지 않는다.
- [x] 다른 사이트 요청 거부를 POST에서 GET이 아닌 모든 요청으로 넓힌다. 다른 출처의 PUT은 로그인돼 있어도 403 `forbidden_origin`이고 파일이 바뀌지 않는다. 기존 POST 동작은 그대로다.
- [x] 화면: 불러오는 중 표시, 불러오기 실패 시 원인과 "다시 시도"(편집 불가), 두 안내 문구가 보인다.
- [x] 제외종목: 기존 종목 검색 훅으로 입력창 아래에 결과를 펼치고, 누르면 추가하고 검색어를 비운다. 이미 추가된 종목은 "추가됨"이다. 목록에 종목명·종목코드(미국은 거래소)와 삭제 버튼이 있고, 비면 "제외종목이 없습니다"가 보인다. 모든 SL/TP 세션에 공통 적용됨을 보여준다. 검색 실패 원인이 보인다.
- [x] "저장"은 변경이 없으면 막히고, 변경이 있으면 "저장하지 않은 변경"이 보인다. 저장 중에는 저장 버튼과 제외종목 검색·추가·삭제가 모두 막힌다. 성공하면 "SL / TP 설정을 저장했습니다" 토스트와 함께 서버 응답 값으로 바뀌고, 실패하면(401 제외) 원인이 담긴 실패 토스트와 함께 입력이 남는다.
- [x] 조회·저장 로그에 투자 환경, 요청 ID, 결과, 제외종목 수, 세션 수, 켜진 세션 수, 실패 원인이 남는다. 설정 내용 전체는 남기지 않는다.
- [x] pytest(임시 저장 폴더, 키움 호출 없음)와 Playwright(가짜 `/api` 응답, 저장 응답을 늦게 주는 경우 포함)로 위 동작을 검증하고, 모바일 폭에서 가로 스크롤이 없다. 기존 테스트가 모두 통과한다.
