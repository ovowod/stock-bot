# 03: 세션별 ON/OFF와 익절·손절 기준, 실전 차단

**What to build:** SL/TP 세션마다 ON/OFF 스위치(기본 OFF)와 익절 기준·손절 기준을 정해 저장한다. 손절 기준은 양수로 입력하고 음수로 보인다. 켜진 세션은 기준이 하나 이상 있어야 한다. 실전투자 환경에서는 스위치를 켤 수 없고, 화면을 우회해도 서버가 거부한다.

Spec: `.scratch/sl-tp/spec.md` (검사 규칙의 기준 값, 자체 서버 API의 실전 ON 거부, 화면)

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 세션마다 스위치, 익절 기준(예: 5 → +5%), 손절 기준(예: 3 → −3%) 입력이 있다. 새 세션은 OFF, 두 기준은 비어 있다.
- [ ] 화면과 서버 모두: 기준은 `null` 또는 소수점 둘째 자리까지의 양수 문자열이고, 익절 0.01~1000, 손절 0.01~99.99다. 한쪽만 있어도 된다. 켜진 세션은 하나 이상 있어야 하고, 꺼진 세션은 둘 다 비어도 된다. 어긋나면 화면은 그 칸에 안내를 보이고 저장을 막고, 서버는 400 `invalid_sl_tp_settings`에 위치를 담는다.
- [ ] 02의 "OFF·기준 없음만" 제한을 푼다.
- [ ] 실전 환경(`can_enable=false`)은 스위치가 OFF로 고정되어 눌리지 않고 "실전투자에서는 SL/TP 세션을 켤 수 없습니다"가 보인다. 실전 제외종목·세션 시각·기준은 저장할 수 있다.
- [ ] 실전 환경에 켜진 세션을 PUT하면 입력 검사 뒤 403 `sl_tp_enable_not_allowed`이고 파일이 바뀌지 않는다. 모의 환경은 켜진 세션을 저장한다.
- [ ] 실전 환경 파일에 켜진 세션이 있으면(직접 고치거나 다른 환경 파일을 복사한 경우) GET은 500 `sl_tp_settings_unreadable`이고 파일은 그대로다.
- [ ] 저장 중에는 스위치와 기준 입력도 막힌다.
- [ ] 저장 로그의 켜진 세션 수와 실전 ON 거부 결과가 남는다.
- [ ] 테스트에 소수점 셋째 자리·0·음수·범위 초과·숫자 아닌 값 거부, 한쪽만 있는 세션 허용, 켜진 세션의 기준 없음 거부, 실전 ON 거부와 파일 유지를 포함한다.
- [ ] pytest와 Playwright로 위 동작을 검증하고, 모바일 폭에서 가로 스크롤이 없다. 기존 테스트가 모두 통과한다.
