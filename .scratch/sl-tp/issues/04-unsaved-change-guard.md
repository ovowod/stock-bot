# 04: 저장하지 않은 변경 보호

**What to build:** SL / TP 화면에 저장하지 않은 변경이 있을 때 투자 환경을 바꾸거나, 다른 메뉴로 가거나, 로그아웃하려 하면 "저장하지 않은 변경이 사라집니다. 이동할까요?"라고 묻는다. 취소하면 화면과 입력이 그대로 남는다. 새로고침·탭 닫기에는 브라우저가 경고한다. 변경이 없으면 묻지 않는다.

Spec: `.scratch/sl-tp/spec.md` (화면의 저장하지 않은 변경)

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 앱 껍데기(투자 환경 전환, 메뉴 이동, 로그아웃)가 SL / TP 화면의 "저장하지 않은 변경" 상태를 알 수 있다.
- [ ] 변경이 있으면 세 가지 이동 모두 브라우저 확인 창으로 묻고, 취소하면 이동하지 않으며, 확인하면 이동하고 변경을 버린다.
- [ ] 변경이 있으면 새로고침·탭 닫기에 브라우저 기본 경고가 뜬다.
- [ ] 변경이 없거나 저장한 뒤에는 묻지 않고 이동한다. 다른 화면의 이동 동작은 바뀌지 않는다.
- [ ] 로그인 만료(401 응답, 입력 없음 만료)는 사용자가 한 이동이 아니므로 묻지 않고 기존대로 로그인 화면으로 가며, 저장하지 않은 입력은 버린다.
- [ ] Playwright로 확인 창의 취소·확인, 변경 없음의 무확인 이동, 변경이 있을 때 401 응답이면 확인 창 없이 로그인 화면으로 가는 것을 검증한다. 기존 테스트가 모두 통과한다.
