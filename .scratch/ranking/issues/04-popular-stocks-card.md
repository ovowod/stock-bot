# 04: 인기 종목 카드

**What to build:** 순위 화면에 **인기 종목** 카드가 추가되어 네 카드가 모두 갖춰진다. 카드 안에서 집계 구간(30초/1분/10분/1시간/당일, 기본값 1시간)을 고르고, 바꾸면 이 카드만 다시 조회한다. 카드에는 "전체 거래소"와 "기준 HH:MM" 집계 시각이 표시되고, 각 줄에 집계 시점 가격과 순위 변동이 보인다.

Spec: `.scratch/ranking/spec.md`

**Blocked by:** 01, 03

**Status:** ready-for-agent

- [ ] `GET .../rankings/popular`가 국내는 `ka00198`(`qry_tp`), 미국은 `usa01980`(`svc_type`)을 호출한다. `period` 쿼리(`30s`/`1m`/`10m`/`1h`/`today`, 없으면 `1h`)를 키움 코드로 바꾸고, 잘못된 값은 400으로 거부하고 키움을 호출하지 않는다. `exchange`는 받지 않는다.
- [ ] 가격은 집계 시점 가격(국내 `past_curr_prc`, 미국 `curr_pric`), 등락은 국내 `base_comp_sign`·`base_comp_chgr`, 미국 `sign_for_gjga`·`diff_rate_for_gjga`를 쓴다.
- [ ] 순위 변동은 올라간 칸 수 양수, 내려간 칸 수 음수, 변동 없음 0이다. 국내는 방향을 `rank_chg_sign`, 크기를 `rank_chg`의 절댓값으로 정한다. 미국은 01의 확인 결과를 따른다(애매하면 미국 순위 변동 칸을 뺀다).
- [ ] 집계 시각은 국내는 1위 항목의 `dt`·`tm`, 미국은 최상위 `base_date`·`base_time`(KST)이다. 구할 수 없으면 `null`이고 화면에서 "기준" 표시를 숨긴다.
- [ ] 카드는 거래량 카드 다음 순서로 조회되고, 거래소를 바꿔도 다시 조회되지 않는다. 집계 구간을 바꾸면 이 카드만 즉시 skeleton으로 바뀌고 다시 조회한다.
- [ ] 각 줄에 순위, 종목명·코드, 기준가(아래에 등락률), 순위 변동(▲2 / ▼1 / −)이 보인다.
- [ ] 가짜 응답 테스트(Seam 1)와 Playwright 화면 테스트(Seam 2)가 위 동작을 확인한다: 집계 구간 코드 변환, 순위 변동, 빈 목록의 `null` 집계 시각, 집계 구간 변경 시 이 카드만 재조회.
- [ ] 네 카드를 모두 띄운 상태로 국내 모의와 미국 모의 서버에서 실제 조회를 확인하고, 데스크톱(1440px)과 모바일(390px) 스크린샷을 찍는다.
