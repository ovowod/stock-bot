# 03: 상승률·거래량 카드와 순서대로 조회

**What to build:** 순위 화면에 **상승률 상위**와 **거래량 상위** 카드가 추가된다. 화면에 들어오거나 새로고침하면 거래대금 → 상승률 → 거래량 카드를 위에서부터 한 번에 하나씩 조회해 차례로 채운다. 한 카드가 실패해도 나머지는 정상으로 보이고, 실패한 카드만 다시 시도할 수 있다. 거래소를 바꾸면 세 카드가 함께 다시 조회된다.

Spec: `.scratch/ranking/spec.md`

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] `GET .../rankings/gainers`가 국내는 `ka10027`(`sort_tp=1`), 미국은 `usa20910`(`sort_tp=1`)을 spec의 요청 본문으로 호출하고, 거래량(국내 `now_trde_qty`, 미국 `trde_qty`)을 담는다.
- [ ] `GET .../rankings/volume`이 국내는 `ka10030`(`sort_tp=1`), 미국은 `usa20530`(`qry_tp=0`)을 spec의 요청 본문으로 호출하고, 거래량(국내 `trde_qty`, 미국 `acc_trde_qty`)을 담는다.
- [ ] 순위 필드가 없는 `ka10027`·`ka10030`은 응답 목록 순서(1부터)를 순위로 쓴다.
- [ ] 상승률 카드는 등락률을 크게, 거래량 카드는 거래량을 지표로 표시한다.
- [ ] 화면에 들어오거나 새로고침하면 세 카드를 순서대로, 앞 카드의 조회가 끝난 뒤에(성공이든 실패든) 다음 카드를 조회한다.
- [ ] 한 카드가 실패해도 다음 카드 조회는 계속되고, 실패한 카드에만 오류와 "다시 시도"가 보인다. 다시 시도하면 그 카드만 다시 요청한다.
- [ ] 거래소를 바꾸면 세 카드가 즉시 skeleton으로 바뀌고 순서대로 다시 조회한다.
- [ ] 새로고침 버튼은 어느 카드든 조회 중이면 비활성화된다. 마지막 조회 시각은 가장 최근에 성공한 카드 조회의 시각이다.
- [ ] 가짜 응답 테스트(Seam 1)와 Playwright 화면 테스트(Seam 2)가 위 동작을 확인한다: TR·본문·순위 대체, 순차 요청 순서, 부분 실패와 다시 시도, 거래소 변경 시 세 카드 재조회.
- [ ] 국내 모의와 미국 모의 서버로 실제 조회해 세 카드가 표시되는 것을 확인한다.
