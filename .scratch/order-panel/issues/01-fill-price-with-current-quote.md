# 01: 현재가로 가격 칸 채우기

**What to build:** 순위나 종목 검색에서 종목을 눌러 주문 패널이 열리면, 서버가 키움에서 그 종목의 현재가를 조회해 가격 칸을 채운다. 수량은 1로 시작한다. 어느 화면에서 열든 같은 방식으로 지금 가격이 채워지고, 순위에서 넘겨받던 가격(인기 종목의 집계 시점 가격 포함)은 더 이상 가격 칸에 쓰지 않는다.

Spec: `.scratch/order-panel/spec.md` (현재가 조회)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 자체 서버에 현재가 조회 API(`GET /api/environments/{environment}/quote?code=&exchange=`)가 있고, 국내는 `ka10001`(`stk_cd`), 미국은 `usa20101`(`stex_tp`, `stk_cd`)을 선택한 투자 환경의 도메인으로 호출한다.
- [ ] 부호 있는 `cur_prc`를 절댓값으로 돌려주고, 빈 값은 `null`, 필드가 없거나 숫자가 아니면 응답 형식 오류(502)다.
- [ ] 미국에서 거래소가 없거나 NYSE·NASDAQ·AMEX가 아니면 400이고 키움을 부르지 않는다.
- [ ] 패널이 열리면 현재가를 한 번 조회하고, 불러오는 동안 가격 칸에 불러오는 중임이 보인다.
- [ ] 조회한 현재가는 사용자가 가격 칸을 아직 건드리지 않았을 때만 채운다.
- [ ] 조회에 실패하면 "현재가를 불러오지 못했습니다" 안내를 보여준다. 사용자가 가격 칸을 건드리지 않았으면 빈칸으로 두고, 이미 입력했으면 그 값을 그대로 둔다(입력 뒤 늦게 오는 실패 포함).
- [ ] 미국 미지원 거래소 종목은 현재가를 조회하지 않는다.
- [ ] 패널을 닫으면 진행 중인 조회를 취소하고 그 응답은 반영하지 않는다.
- [ ] 수량 칸이 1로 시작하고 예상 주문금액이 바로 계산된다.
- [ ] 순위 화면이 주문 패널에 가격을 넘기지 않는다. spec의 "인기 종목 가격을 채우지 않는다" 규칙은 현재가 조회로 대체된 것으로 정리한다.
- [ ] pytest(가짜 키움 서버)와 Playwright(`/api` 가짜 응답)로 위 동작을 검증하고, 기존 테스트가 모두 통과한다.
