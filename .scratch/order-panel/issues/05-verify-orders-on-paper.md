# 05: 모의투자 서버에서 주문 직접 확인

**What to build:** 국내 모의와 미국 모의 서버에 실제로 매수 주문을 넣어, 문서로 확인되지 않은 주문 동작을 확인하고 결과를 spec에 기록한다. 실전 서버로는 조회를 포함해 어떤 요청도 보내지 않으므로, 앱에서 실전 환경을 고르지 않는다. 실전 차단은 02·03의 자동 테스트(가짜 `/api` 응답, 가짜 키움 서버)로 이미 검증한다.

Spec: `.scratch/order-panel/spec.md` (Further Notes)

**Blocked by:** 03, 04

**Status:** ready-for-human

- [ ] 국내 모의·미국 모의 환경에서만 확인한다. 실전 환경으로 전환하지 않는다.
- [ ] 국내 모의에서 지정가·시장가 1주 주문이 접수되는지, 주문번호가 오는지 확인한다.
- [ ] 미국 모의에서 NYSE·NASDAQ·AMEX 종목의 지정가·시장가 1주 주문이 접수되는지 확인한다.
- [ ] 장 시간 밖에 주문했을 때 키움 거부 메시지가 알림에 어떻게 보이는지 확인한다.
- [ ] 국내 `kt10000` 응답에 `dmst_stex_tp`가 오는지 확인한다.
- [ ] 미국 주문 가격을 소수 몇째 자리까지 받는지 확인한다(예: 소수 둘째·넷째 자리 가격).
- [ ] 호가 단위에 맞지 않는 국내 가격의 거부 메시지를 확인한다.
- [ ] 결과를 spec 끝의 `## Implementation Notes`에 날짜와 함께 기록한다. 로그나 기록에 인증정보·토큰·계좌번호가 남지 않게 한다.
- [ ] 확인 결과로 spec이나 구현을 바꿔야 할 점이 있으면 정리해서 결정을 받는다.
