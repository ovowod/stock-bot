# 주문 패널 (매수 인터페이스)

Status: ready-for-agent

## Problem Statement

순위나 종목 검색에서 관심 종목을 찾아도 대시보드 안에서 바로 매수를 준비할 방법이 없다. 이후 자동매매·수동 주문을 붙이려면 먼저 어느 화면에서든 종목을 골라 주문 내용을 입력하는 화면이 필요하다. 모의투자는 지원하는 시장과 종목이 제한되어 있어, 매수할 수 없는 종목이면 이유를 알아야 한다.

## Solution

순위와 종목 검색 결과의 종목을 누르면 **주문 패널**이 열린다. 데스크톱은 오른쪽에서 밀려 나오는 패널, 모바일은 아래에서 올라오는 시트다. 패널은 선택한 투자 환경의 시장에 맞는 **매수 주문** 입력 항목을 보여준다. 이번에는 인터페이스만 만들고 주문은 전송하지 않는다. 매수 버튼은 비활성화하고 "주문 전송은 아직 지원하지 않습니다"라고 안내한다.

## User Stories

1. As a 투자자, I want 순위 카드의 종목을 누르면 주문 패널이 열리기를, so that 순위를 보다가 바로 매수를 준비한다.
2. As a 투자자, I want 종목 검색 결과를 누르면 주문 패널이 열리기를, so that 찾은 종목을 바로 매수 준비한다.
3. As a 투자자, I want 주문 패널이 열려도 보던 목록이 그대로 남아 있기를, so that 닫으면 하던 일을 이어 간다.
4. As a 투자자, I want 닫기 버튼, 바깥 영역, Esc로 패널을 닫기를, so that 익숙한 방법으로 닫는다.
5. As a 투자자, I want 투자 환경을 바꾸면 열린 패널이 닫히기를, so that 다른 환경의 종목으로 주문을 준비하지 않는다.
6. As a 투자자, I want 패널 위쪽에서 종목명, 종목코드(티커), 거래소(국내는 종목 구분)를 보기를, so that 어떤 종목인지 확인한다.
7. As a 투자자, I want 주문 유형으로 지정가와 시장가를 고르기를, so that 가격을 정하거나 바로 사는 방식을 고른다.
8. As a 투자자, I want 지정가일 때만 가격 칸이 보이기를, so that 시장가에서 쓰지 않는 값을 입력하지 않는다.
9. As a 투자자, I want 순위에서 연 종목은 현재가가 가격 칸에 미리 채워지기를(인기 종목 제외), so that 가격을 처음부터 입력하지 않아도 된다.
10. As a 투자자, I want 수량과 가격이 올바르지 않으면 이유를 보기를, so that 무엇을 고쳐야 하는지 안다.
11. As a 투자자, I want 지정가 주문의 예상 주문금액(수량 × 가격)을 보기를, so that 얼마가 드는지 가늠한다.
12. As a 투자자, I want 실전투자 환경에서는 패널에도 "실전" 표시가 있기를, so that 실제 계좌라는 것을 잊지 않는다.
13. As a 미국 모의투자 사용자, I want NYSE·NASDAQ·AMEX가 아닌 종목에는 매수 칸 대신 이유를 보기를, so that 왜 매수할 수 없는지 안다.
14. As a 국내 투자자, I want 관리종목·거래정지 등 상태가 있는 종목이면 경고를 보기를, so that 주의해서 주문한다.
15. As a 모바일 사용자, I want 패널이 화면 아래에서 올라오고 가로 스크롤이 생기지 않기를, so that 휴대폰에서도 편하게 쓴다.
16. As a 키보드 사용자, I want 패널이 열린 동안 뒤쪽 화면으로 초점이 넘어가지 않고, 닫으면 눌렀던 종목으로 초점이 돌아오기를, so that 목록에서 보던 위치를 잃지 않는다.

## Implementation Decisions

**재사용 방식**

- 앱 전체에 주문 패널 하나를 두고, 어느 화면에서든 "이 종목으로 주문 패널 열기"만 호출하면 열린다. 화면은 종목코드, 종목명, 거래소(또는 종목 구분), 현재가(없으면 비움), 상태(없으면 비움)만 넘긴다.
- 투자 환경은 패널이 앱에서 직접 받는다. 투자 환경이 바뀌면 패널을 닫는다.
- 패널은 넘겨받은 정보만 보여준다. 국내 순위 데이터에는 종목 구분과 상태가 없으므로, 순위에서 연 국내 종목은 종목 구분을 표시하지 않고 상태 경고도 나오지 않는다(정상인지 상태를 모르는지 구별하지 않는다).
- 인기 종목의 가격은 집계 시점 가격이므로 가격 칸에 채우지 않는다. 나머지 순위 카드의 가격만 현재가로 채운다.
- 패널이 열린 동안 뒤쪽 화면을 `inert`로 막고, 닫으면 패널을 열었던 요소로 초점을 되돌린다.
- 이번에 연결하는 곳: 순위 카드 4종의 종목 줄, 종목 검색 결과 줄. 계좌 확인의 보유종목은 매도와 함께 연결한다.

**주문 유형**

| 화면 표기 | 국내 `kt10000` `trde_tp` | 미국 `ust20000` `trde_tp` |
|---|---|---|
| 지정가 | `0` (보통) | `00` |
| 시장가 | `3` | `03` |

- 지금은 이 두 가지만 지원한다. 나머지 매매구분은 이후 지원한다(Out of Scope 참고).
- 시장가는 가격을 입력받지 않는다(국내 예제는 `ord_uv`를 빈 값으로 보내고, 미국 문서는 시장가 계열이면 빈 값이라고 적는다).

**입력 검사**

- 수량: 1 이상의 정수.
- 가격(지정가만): 0보다 큰 수. 국내는 원 단위 정수. 미국 가격의 허용 소수 자릿수는 문서(`ust20000`)에 없어 제한하지 않는다.
- 미국 예상 주문금액은 소수 넷째 자리까지 표시한다(순위의 미국 가격 표시와 같다). 1달러 미만 가격도 0으로 보이지 않는다.
- 호가 단위 검사는 하지 않는다. 실제 전송을 붙일 때 다룬다.

**매수 가능 여부** (문서로 확인되는 기준만 적용한다)

- 미국: 매수 TR의 거래소 값이 `NA`(AMEX)·`ND`(NASDAQ)·`NY`(NYSE)뿐이고, 미국 모의투자도 이 세 거래소만 지원한다. 거래소가 이 셋이 아니거나 알 수 없으면 매수 칸 대신 이유를 보여준다.
- 국내: 모의투자는 KRX만 지원한다. 순위·검색 목록은 코스피·코스닥 종목이고 주문은 KRX로 보내므로 막지 않는다.
- 종목 상태(관리종목 등)는 막지 않고 경고만 보여준다. 실제로 거절되는지는 문서에 없다.

**국내 거래소**

- 국내 주문 거래소(`dmst_stex_tp`)는 KRX로 고정하고 선택 칸을 두지 않는다.

**API 호출**

- 이번에는 새 API를 호출하지 않는다. 현재가는 순위에서 넘겨받은 값만 쓴다.

## Testing Decisions

- Playwright e2e로 브라우저의 `/api` 요청을 가짜 응답으로 대체해 검증한다. 키움 서버는 호출하지 않는다.
- 검증 항목: 순위·검색에서 패널 열기, 인기 종목 가격 칸 비움, 뒤쪽 화면 inert와 초점 복원, 1달러 미만 미국 예상 주문금액, 지정가/시장가 전환과 가격 칸, 현재가 미리 채우기, 입력 오류 안내, 예상 주문금액, 매수 버튼 비활성, 미국 모의의 미지원 거래소 안내, 실전 표시, 닫기(버튼·Esc), 환경 전환 시 닫힘, 모바일 가로 스크롤 없음.

## Out of Scope

- 실제 주문 전송(`kt10000`, `ust20000`), 전송 전 확인 화면, 실전 주문 이중 확인.
- 지정가·시장가 외 주문 유형. 이후 지원할 예정이다.
  - 국내 `kt10000`: `5` 조건부지정가, `6` 최유리지정가, `7` 최우선지정가, `10`·`13`·`16` IOC, `20`·`23`·`26` FOK, `28` 스톱지정가(`cond_uv`), `29`·`30`·`31` 중간가, `40`·`46`·`47` GTP, `61` 장시작전시간외, `81` 장마감후시간외.
  - 미국 `ust20000`: `26` VWAP지정가, `27` TWAP지정가, `30` LOC, `36` VWAP시장가, `37` TWAP시장가. 예약 매수(`ust21200`)도 이후 다룬다.
- 국내 NXT·SOR 거래소 주문.
- 호가 단위 검사, 현재가·주문가능수량 조회(`kt00011`, `ust31490`).
- 매도 주문과 보유종목 연결.

## Further Notes

- 문서로 확인하지 못한 것: `cond_uv`를 쓰는 매매구분, 모의투자·거래소별로 허용되는 매매구분, 미국 주문 가격의 허용 소수 자릿수. 실제 전송을 붙일 때 모의투자에서 확인한다.

### 2026-10-05: Codex review
- ✏️ 국내 순위에서 종목 구분·상태 표시를 충족할 수 없음: "넘겨받은 정보만 표시"를 한계로 spec에만 적었다. "상태 확인 안 됨" 문구는 순위에서 연 거의 모든 종목에 붙어 잡음이 되므로 코드는 그대로 둔다.
- ✅ 인기 종목의 집계 시점 가격을 현재가로 취급: 인기 종목에서 열면 가격 칸을 채우지 않는다. 기준 시각 표시보다 단순하고 오해가 없다.
- ✏️ 패널의 배경 조작·초점 복원 규칙 누락: 뒤쪽 화면 `inert`와 초점 복원만 넣었다. 직접 만든 focus trap은 개인 프로젝트에 과하다.
- ✅ 미국 가격 정밀도와 예상 금액 표시 불일치: 예상 주문금액을 소수 넷째 자리까지 표시한다. 입력 자릿수 제한은 문서에 없어 정하지 않고 Further Notes에 남겼다.
