# 06: 모의투자 장중 확인

**What to build:** 국내 모의투자 서버에서 실제로 미체결 목록과 주문 취소를 해 보고, 문서로 확인하지 못한 동작을 기록한다. 결과에 따라 바꿀 것이 있으면 spec을 고칠지 결정을 받는다.

Spec: `.scratch/cancel-order/spec.md` (Further Notes)

**Blocked by:** 04, 05

**Status:** ready-for-human

- [ ] 시작 전에 앱이 국내 모의 환경으로 떠 있고, 미체결·취소 요청이 모의 도메인으로만 나가는지 로그로 확인한다. 실전 도메인 요청이 하나라도 보이면 멈춘다.
- [ ] `ka10075`의 `stex_tp=0`(통합)을 모의 서버가 받아들이는지 확인한다. 거부하면 응답을 기록한다.
- [ ] 모의 주문의 `stex_tp`·`stex_tp_txt`·`sor_yn` 값과, 그 주문이 취소 가능으로 분류되는지 확인한다.
- [ ] 장중에 시장가에서 먼 지정가 매수로 미체결을 만들고, 목록에 나오는지 확인한다.
- [ ] 일부 취소와 전부 취소(`cncl_qty=0`)가 접수되는지, 응답 `cncl_qty`가 실제 취소 수량인지 0인지 확인한다.
- [ ] 취소 접수 직후 다시 조회한 목록에 그 주문이 남는지, 남는다면 얼마나 남는지 확인한다.
- [ ] Discord에 "주문 취소 접수" 알림이 오는지 확인한다.
- [ ] 결과를 spec의 Implementation Notes에 날짜와 함께 기록한다.
