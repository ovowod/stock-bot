# 02: 매도 단계 전에 정할 것 (실측과 판정 규칙)

**What to build:** 구현 ticket이 아니다. Dead Cross 자동 매도를 붙이기 전에 사실을 재고 판정 규칙을 정한다. 다음 단계를 시작할 때 이 ticket으로 그릴링하고, 결과로 매도 단계의 spec을 쓴다.

Spec: `.scratch/dead-cross/spec.md`

**Blocked by:** 01

**Status:** needs-triage

**모의투자 실측 (키움 명세에 없음)**

- [ ] 시장(국내 `ka10080`·`ka10081`, 미국 `usa06011`·`usa06012`)과 봉 주기마다 한 번에 오는 봉 수를 잰다.
- [ ] 연속조회로 얼마나 과거까지 거슬러 받을 수 있는지 잰다. 분봉은 며칠 전까지 오는지를 본다.
- [ ] 결과에 맞춰 이동평균 기간 상한(지금은 앱이 정한 120)을 그대로 둘지, 봉 주기마다 다르게 둘지 정한다.
- [ ] 국내 `base_dt`(기준일자)와 미국 `strt_dt`(시작일자)가 각각 어느 방향으로 봉을 주는지 확인한다.

**판정 규칙**

- [ ] 일봉의 하향 돌파는 장 마감에 완료돼 늘 세션 밖에 놓인다. 다음 거래일의 켜진 세션에서 처리할지, 처리한다면 언제 할지 정한다.
- [ ] 세션 경계(예: 10:00)에서 완료된 분봉을 앞 세션과 뒤 세션 가운데 어느 쪽이 판정할지, 두 세션의 봉 주기가 다르면 어떻게 할지 정한다.
- [ ] 국내 60분봉의 마지막 봉(15:00–15:30)처럼 길이가 짧은 봉을 완료된 봉으로 볼지 정한다.
- [ ] 이동평균에 필요한 봉이 모자랄 때(상장 직후, 조회 실패) 어떻게 할지 정한다.
- [ ] 한 세션 동안 종목마다 트리거를 몇 번 할지, 매도가 실패하면 다시 낼지 정한다.
- [ ] 수정주가를 쓸지 정한다.
- [ ] 같은 종목에 SL / TP나 Trailing Stop의 자동 매도가 겹칠 때 **자동 매도** 규칙대로 하나만 진행하는지 확인한다.
- [ ] 차트 조회가 호출 한도 안에 드는지 확인한다. 보유종목 수 × 봉 완료마다 조회가 필요하다.
- [ ] 매도 동작을 붙일 때 화면의 준비 중 안내를 지운다.
