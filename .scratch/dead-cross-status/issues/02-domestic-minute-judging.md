# 02: 국내 분봉 이동평균과 하향 돌파 판정

**What to build:** 국내 모의투자에서 켜진 Dead Cross 세션 동안, 보유종목의 분봉 차트를 받아 완료 봉만으로 단기·장기 이동평균을 계산하고 하향 돌파를 판정한다. Dead Cross 보기에 이동평균 값, 마지막 판정 봉 시각, 추적 중/데드크로스 발생 상태가 보인다. 판정 결과는 이번에는 메모리에만 둔다.

Spec: `.scratch/dead-cross-status/spec.md`

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 구현 전에 kra-docs로 `ka10080`의 요청·응답 필드를 다시 확인한다.
- [x] 차트는 마지막 판정 봉 다음부터 최신 완료 봉까지와 그 판정에 필요한 과거 봉이 모일 때까지 연속조회한다. 페이지 상한은 없고, 평소에는 1페이지에서 멈춘다. 기존 "최대 10페이지 다 받기"는 쓰지 않는다. 기존 키움 호출 간격 규칙을 지킨다.
- [x] 과거 범위가 끝나(`cont-yn=N`) 필요한 봉을 다 받지 못하면 가장 최근 완료 봉 하나만 판정하고 로그를 남긴다.
- [x] `시작 시각 + 봉 주기 ≤ 지금`인 봉만 완료 봉이다. 진행 중인 맨 앞 봉은 이동평균에 들어가지 않는다. 가격의 `+`/`-` 부호를 떼고 쓴다. 정규장 밖 봉도 그대로 쓴다.
- [x] 마지막 판정 봉 뒤의 완료 봉을 오래된 것부터 차례로 판정한다. 처음 보는 종목이나 봉 주기·단기·장기 기간 가운데 하나라도 바뀐 종목은 가장 최근 완료 봉 하나만 새 기준으로 판정한다(발생은 남고 풀림만 새 기준).
- [x] 직전 봉 `단기 ≥ 장기`, 이번 봉 `단기 < 장기`이면 데드크로스 발생이고 발생 시각과 발생 봉을 보인다. 이미 낮은 상태로 시작하면 추적 중이다.
- [x] 데드크로스 발생은 세션 밖에서도 남고, 판정한 봉에서 단기가 다시 장기 이상이 되거나, 전량 매도하거나, 제외종목으로 저장하면 풀린다. 설정을 바꿔도 발생은 남고 풀림은 지금 설정으로 판정한다.
- [x] 늦게 들어온 봉과 조회 실패 뒤 빠진 봉을 다음 조회에서 차례로 판정해 하향 돌파를 잡는다.
- [x] 조회 시점: 세션 시작, Dead Cross 설정 저장, 새 보유종목, 봉이 끝난 5초 뒤(시계 기준). 조회 차례마다 그 앞에 보유종목을 한 번 다시 읽어, 체결을 받지 못한 매수·매도도 반영한다.
- [x] 차트 응답을 기다리는 사이 제외종목 저장, 전량 매도, 세션 변경이 일어나면 그 응답을 버린다.
- [x] 투자 환경마다 조회 차례는 하나만 돈다. 도는 동안 들어온 요청은 끝난 뒤 한 차례로 합친다. 조회가 봉 주기보다 오래 걸려도 차례가 겹치지 않고, 마지막 판정 봉은 뒤로 가지 않는다.
- [x] 화면의 이동평균은 조회할 때마다 가장 최근 완료 봉으로 다시 계산한다(이미 판정한 봉이면 상태는 그대로). 응답에 계산 기준 `basis`를 담고, 지금 세션과 다르면 화면에 이전 기준 값으로 표시한다.
- [x] 차트 조회가 실패하면 추적 중·데드크로스 발생은 그대로 두고 이유만 붙인다(판정한 적 없는 종목은 계산 대기 · 차트 조회 실패). 같은 세션 안에서 보유종목 읽기와 같은 방식으로 다시 시도하고, 성공하면 빠진 봉을 차례로 판정한다. 세션이 끝나면 그만둔다.
- [x] 계산 대기 이유에 봉 부족(장기 기간 + 1개 미만)과 차트 조회 실패가 더해진다. 매입가 없는 종목도 계산한다.
- [x] 이동평균은 소수 둘째 자리 문자열로 응답하고 화면에 "단기 61,230.40 · 장기 61,012.75"처럼 보인다. 판정은 반올림 전 값으로 한다.
- [x] 차트 조회, 판정, 하향 돌파, 풀림, 기억 삭제 로그가 요청 ID와 spec의 필수 칸을 담는다. 변화 없는 판정은 DEBUG다.
- [x] 어떤 테스트에서도 매도 주문 TR이 나가지 않는다. 테스트, lint, 타입 검사, 화면 빌드가 통과한다.
