# 04: 미국 시장과 일봉, 설정 화면 안내 문구

**What to build:** 미국 모의투자에서도 Dead Cross 상태가 계산되고, 두 시장 모두 일봉으로 판정된다. Dead Cross 설정 화면의 준비 중 안내가 상태 보기를 가리키도록 바뀐다.

Spec: `.scratch/dead-cross-status/spec.md`

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [x] 구현 전에 kra-docs로 `usa06011`, `usa06012`, `ka10081`의 요청·응답 필드를 다시 확인한다.
- [x] 미국 분봉은 `stex_tp`를 보유종목의 거래소로 정하고, `strt_dt`는 뉴욕 기준 오늘이다. `cntr_tm`을 뉴욕 시각으로 읽고 24시 넘는 시각(`20261030264000` = 10/31 02:40)을 다음 날로 바꾼다.
- [x] 미국도 국내와 같은 규칙으로 필요한 만큼 연속조회한다(평소 2페이지, 하룻밤 쌓인 1분봉은 그 이상). 120분봉의 봉 끝 시각은 04:00 기준 2시간 간격으로 계산한다.
- [x] 미국 이동평균은 소수 넷째 자리로 응답하고 기존 외화 표기로 보인다.
- [x] 일봉 조회가 세션 시작에서 실패해도 같은 세션 안에서 다시 시도해 판정한다.
- [x] 일봉은 그 시장의 오늘(국내 한국 시각, 미국 뉴욕 시각) 행을 빼고 앞선 날만 완료 봉으로 쓴다. 장 마감 뒤 완료된 일봉은 다음 켜진 세션 시작에서 판정한다(휴장일 달력은 보지 않는다).
- [x] Dead Cross 설정 화면의 준비 중 안내가 "지금은 상태만 계산하고 팔지 않습니다. 계좌 확인 화면의 Dead Cross 보기에서 확인하세요."로 바뀐다.
- [x] 어떤 테스트에서도 매도 주문 TR이 나가지 않는다. 테스트, lint, 타입 검사, 화면 빌드가 통과한다.
