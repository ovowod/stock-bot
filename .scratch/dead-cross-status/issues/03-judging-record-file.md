# 03: 판정 기록 파일

**What to build:** 데드크로스 발생과 마지막 판정 봉이 투자 환경마다 파일에 저장돼, 서버를 다시 시작해도 이어진다. 세션 밖에서 완료된 봉은 다음 켜진 세션에서 판정된다.

Spec: `.scratch/dead-cross-status/spec.md`

**Blocked by:** 02

**Status:** ready-for-agent

- [x] 데이터 폴더 아래에 투자 환경마다 spec의 버전 1 형식 파일이 생긴다. 자동매매 설정 파일, Trailing Stop 고점 기록과 따로다. `.env`에 새 변수가 없다.
- [x] 판정할 때마다 임시 파일에 쓴 뒤 바꿔치기한다. 기억 삭제(전량 매도, 제외종목, 보유에서 빠짐)도 바로 쓴다.
- [x] 같은 데이터 폴더로 앱을 다시 띄우면 데드크로스 발생, 발생 시각·봉, 마지막 판정 봉이 그대로다. 다음 날로 시계를 옮겨도 남는다.
- [x] 다시 시작한 뒤 새 완료 봉이 없어도 첫 조회에서 이동평균 값이 다시 보이고, 상태는 바뀌지 않는다.
- [x] 기억이 있는 동안 세션 밖에서도 내 계좌 체결을 받는다. 세션이 끝난 뒤 전량 매도하면 메모리와 파일에서 기억이 지워지고, 다시 시작해도 되살아나지 않는다.
- [x] 세션 밖에서 완료된 봉(세션 뒤 분봉, 시간외 분봉)을 다음 세션 시작에서 차례로 판정한다.
- [x] 파일이 없으면 빈 기록이다. 깨진 파일은 그 환경의 판정을 멈추고 `state_unreadable`을 돌려주며, 고친 뒤 Dead Cross 설정을 저장하면 다시 읽어 판정한다.
- [ ] 쓰기에 실패하면 메모리 판정은 계속하고 로그를 남긴 뒤 다음 쓰기 때 다시 시도한다. (구현했지만 쓰기 실패는 테스트하지 않음)
- [ ] 기록 읽기·쓰기 실패가 로그에 남는다. (구현했지만 쓰기 실패는 테스트하지 않음)
- [x] 어떤 테스트에서도 매도 주문 TR이 나가지 않는다. 테스트, lint, 타입 검사, 화면 빌드가 통과한다.
