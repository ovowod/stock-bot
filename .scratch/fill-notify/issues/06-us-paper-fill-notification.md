# 06: 미국 모의 체결 알림

**What to build:** 미국 모의 계좌의 체결도 국내와 같은 모양의 체결 알림으로 온다. 실시간 항목은 `F5`, 미체결 주문은 `ust21050`, 매입가는 `ust21630`이고, 가격과 금액은 USD로 보인다. 매도 손익은 서버가 주문번호별로 받은 체결 금액을 더해서 계산한다.

Spec: `.scratch/fill-notify/spec.md` (연결 단위, 이벤트 처리, 미체결 주문 조회, 매도 손익, 알림 모양)

**Blocked by:** 01, 03, 04

**Status:** ready-for-agent

- [ ] Discord 알림이 켜져 있고 미국 모의 인증정보가 있으면 미국 모의 연결을 열고, 01에서 확인한 `item` 형식으로 `F5`를 등록한다.
- [ ] 01에서 확인한 `913` 체결 상태 값만 알림을 만든다. `907`은 01 매도, 02 매수다.
- [ ] 알림에 `[미국 모의]` 접두어, 종목명과 티커, 이번 체결 수량 @ USD 가격 (금액), 누적/주문 수량과 남은 수량 또는 "전량 체결", 체결 시각(KST)이 보인다. USD는 소수 둘째 자리로 보여준다.
- [ ] 미체결 주문은 `ust21050`(빈 값, `slby_tp=0`)으로 조회하고, 한 줄에 `frgn_stk_nm`, `slby_tp_nm`, `frgn_trde_nm`, `ord_uv`, `ord_remnq`/`ord_qty`, `ord_time`을 보여준다. 10건 제한, "외 N건", "없음", 시장가 표시, 연속조회 10페이지 한도, 1024자 줄 단위 자르기, "조회 실패"는 03과 같다.
- [ ] 매도 체결이면 `ust21630`을 티커, 종목 목록에서 찾은 거래소(`stex_tp`), `fc_krw_tp=0`으로 조회해 같은 `stk_cd` 줄의 `avg_buy_uv`를 매입가로 쓴다.
- [ ] 매도 손익은 같은 주문번호로 받은 (체결가 × 체결량)의 합 − 매입가 × 누적 체결 수량이다. 합계는 서버 메모리에 (투자 환경, 주문번호)별로 두고, 전량 체결되면 지우며 마지막 체결 후 24시간이 지난 항목도 지운다. 날짜가 바뀌어도 비우지 않는다.
- [ ] 서버 재시작 등으로 받은 체결량의 합이 누적 체결 수량보다 작으면 손익은 "조회 실패"다. 이번 체결분을 늘려서 추정하지 않는다.
- [ ] 체결 이벤트 값을 읽지 못할 때의 "확인 불가" 처리와 알림 순서 보장은 02·04와 같다.
- [ ] 익절·손절·본절 판정, 색, 조회 실패 처리는 04와 같다. 비교와 표시는 USD 소수 둘째 자리 기준이다.
- [ ] 테스트는 kra-docs `F5`, `ust21050`, `ust21630` responseExample 모양의 가짜 응답으로 매수, 분할 매도 누적 손익, 한국 자정을 넘긴 분할 체결의 누적 손익, 재시작 뒤 조회 실패, 값을 읽지 못한 이벤트를 검증한다.
- [ ] 기존 테스트, lint, format 검사, type 검사가 모두 통과한다.
