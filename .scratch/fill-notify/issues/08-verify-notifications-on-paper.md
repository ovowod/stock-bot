# 08: 모의투자에서 체결 알림 직접 확인

**What to build:** 서버를 실제로 띄운 채 국내 모의와 미국 모의에서 주문을 넣어, 체결 알림이 Discord에 기대한 모양으로 오는지 눈으로 확인하고 결과를 spec에 기록한다. 실전 환경으로는 주문하지 않는다.

Spec: `.scratch/fill-notify/spec.md`

**Blocked by:** 03, 04, 05, 06

**Status:** ready-for-human

- [ ] 국내 모의와 미국 모의에서만 주문한다. 실전 환경으로 주문하지 않는다.
- [ ] 국내 모의·미국 모의에서 1주 매수가 체결되면 매수 알림(빨강, 종목, 이번 체결, 전량 체결, 체결 시각, 미체결 목록)이 온다.
- [ ] 다른 지정가 주문을 걸어 둔 상태에서 체결이 일어나면, 걸어 둔 주문이 미체결 목록에 보인다.
- [ ] 매입가보다 비싸게 팔면 익절, 싸게 팔면 손절 알림이 오고, 손익 금액이 계좌 확인이나 키움 앱의 값과 수수료·세금 차이 안에서 맞는다.
- [ ] 분할 체결이 생기면 알림이 체결마다 오고 마지막에 "전량 체결"이 보인다.
- [ ] MTS·HTS에서 낸 모의 주문의 체결도 알림이 온다.
- [ ] 서버를 켠 채 네트워크를 끊었다가 다시 연결하면 로그에 끊김과 재연결이 남고, 그 뒤 체결 알림이 다시 온다.
- [ ] 로그에 계좌번호, 토큰, 앱 키가 보이지 않는다.
- [ ] 결과를 spec 끝의 `## Implementation Notes`에 날짜와 함께 기록하고, 바꿔야 할 점이 있으면 정리해서 결정을 받는다.
