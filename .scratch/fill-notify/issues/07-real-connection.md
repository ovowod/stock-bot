# 07: 실전 연결 (국내·미국 실전을 연결 하나로)

**What to build:** 실전 인증정보가 있으면 실전 계좌의 국내·미국 체결도 체결 알림으로 온다. 국내 실전과 미국 실전은 인증정보와 계좌가 같으므로 실전 실시간 도메인에 연결 하나를 열고 `00`과 `F5`를 함께 등록한다. 이벤트 종류에 따라 `[국내 실전]`, `[미국 실전]`으로 나눠 보여준다. 체결 감시는 조회만 하고 주문은 보내지 않는다.

Spec: `.scratch/fill-notify/spec.md` (연결 단위, Further Notes)

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 실전 인증정보가 있으면 실전 실시간 도메인에 연결 하나를 열고, 실전 토큰으로 `LOGIN` 후 `00`과 `F5`를 한 번에 등록한다.
- [ ] `00` 이벤트는 국내 실전, `F5` 이벤트는 미국 실전으로 처리한다. 미체결과 매입가 조회는 그 투자 환경의 TR을 실전 REST 도메인으로 호출한다.
- [ ] 국내 체결에는 국내 미체결 주문만, 미국 체결에는 미국 미체결 주문만 붙는다.
- [ ] 미국 실전과 미국 모의에 같은 주문번호의 체결이 와도 누적 손익이 섞이지 않는 것을 테스트로 검증한다.
- [ ] 실전 인증정보가 없으면 실전 연결을 건너뛰고 나머지 연결은 그대로 동작한다.
- [ ] 테스트로 실전 연결이 실전 도메인과 실전 토큰만 쓰고, 모의 연결은 모의 도메인과 각자의 토큰만 쓰는지 검증한다.
- [ ] 테스트로 체결 감시 중에 주문 TR(`kt10000`, `kt10001`, `ust20000`, `ust20001` 등)이 하나도 나가지 않는지 검증한다.
- [ ] 개발 중에는 실전 서버에 연결하지 않는다. 실제 동작(연결 하나로 `00`과 `F5`를 함께 받는지, 실전 `F5` 주문상태 값)은 실전 첫 체결 때 로그로 확인한다는 것을 spec Implementation Notes에 남긴다.
- [ ] 기존 테스트, lint, format 검사, type 검사가 모두 통과한다.
