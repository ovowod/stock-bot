# 02: 국내 모의 체결 알림

**What to build:** 서버가 켜져 있으면 국내 모의 계좌에서 체결이 일어날 때마다 Discord로 체결 알림이 온다. 알림에는 `[국내 모의]` 접두어, `체결 · 매수` 또는 `체결 · 매도` 제목(매수 빨강, 매도는 손익이 붙기 전까지 회색), 종목명과 종목코드, 이번 체결 수량 @ 가격 (금액), 누적/주문 수량과 남은 수량(다 체결되면 "전량 체결"), 체결 시각이 들어간다. 미체결 주문과 매도 손익은 03·04에서 붙인다. 이 기능의 첫 관통 작업이므로 실시간 연결의 기초(실시간 도메인, 접근 토큰 공유, 앱 시작·종료 시 감시 작업, 실시간 연결 seam, 가짜 키움 실시간 서버)를 함께 만든다.

Spec: `.scratch/fill-notify/spec.md` (연결 단위, 앱 수명과 seam, 이벤트 처리, 알림 모양, 로그)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 투자 환경 정의에 실시간 도메인(실전 `wss://api.kiwoom.com:10000`, 모의 `wss://mockapi.kiwoom.com:10000`)을 더하고, path는 `/api/websocket`이다.
- [ ] 실시간 연결이 기존 키움 클라이언트의 접근 토큰 캐시를 함께 쓴다.
- [ ] 앱 생성 함수가 실시간 연결 함수를 바깥에서 받는다. 기본값은 실제 WebSocket 연결이며, `websockets`를 직접 의존성으로 선언한다.
- [ ] 앱이 시작할 때(lifespan) Discord 알림이 켜져 있고 국내 모의 인증정보가 있으면 국내 모의 연결을 연다. 앱이 끝나면 감시 작업을 취소하고 연결을 닫는다. Discord 설정이나 인증정보가 없으면 연결하지 않고 이유를 로그로 남긴다.
- [ ] 연결 후 국내 모의 토큰으로 `LOGIN`을 보내고, LOGIN 성공 응답을 받은 뒤 `REG`로 `00`을 `item: [""]`로 등록한다. REG 응답의 `return_code`가 0이 아니면 오류 로그를 남긴다.
- [ ] `LOGIN`과 `REG` 응답을 각각 10초 안에 받지 못하면 오류 로그를 남기고 연결을 닫는다(다시 연결하는 건 05). 기다리는 시간은 테스트에서 줄일 수 있다.
- [ ] `PING`을 받으면 같은 메시지를 그대로 돌려보낸다. PING 로그는 DEBUG로만 남긴다.
- [ ] 받는 쪽은 메시지를 큐에 넣기만 하고, 작업자가 받은 순서대로 처리한다. 알림 처리가 늦어도 PING 응답이 막히지 않는다.
- [ ] `trnm=REAL` 메시지의 `00` 항목 중 `913` 주문상태가 "체결"인 것만 알림을 만든다. 접수·확인·취소·거부는 낮은 레벨 로그만 남긴다.
- [ ] 숫자 값의 `+`/`-` 부호와 앞의 0을 떼고 읽는다. 누적 체결 수량은 `900` − `902`, `902`가 0이면 "전량 체결"이다. 체결 시각은 `908`을 HH:MM:SS로 보여준다.
- [ ] 알림은 기존 Discord 알림 기능으로 보낸다. 작업자는 전송이 끝날 때까지(재시도 포함) 기다린 뒤 다음 체결을 처리하며, 받는 쪽의 PING 응답은 막히지 않는다. 첫 알림이 429로 재시도해도 같은 주문의 두 알림이 체결 순서대로 도착한다.
- [ ] 체결 이벤트의 값이 없거나 빈 값이거나 숫자가 아니면 경고 로그를 남기고, 그 값과 그 값이 필요한 누적·남은 수량을 "확인 불가"로 보여준 알림을 보낸다. 작업자는 멈추지 않고 다음 정상 체결도 알림이 된다.
- [ ] 체결 하나마다 처리 ID를 만들어 수신과 알림 로그에 붙인다. 연결 시도·성공, LOGIN·REG 결과, 끊김, 감시 시작·종료도 로그로 남긴다. 실시간 이벤트의 계좌번호(`9201`)는 가리고, 토큰은 기존 마스킹으로 가려진다.
- [ ] 테스트는 앱 수명을 실행하고, 가짜 키움 실시간 서버(앱이 보낸 메시지를 기록하고 테스트가 이벤트·PING을 밀어 넣을 수 있음)와 기존 가짜 키움 REST, 가짜 Discord로 바깥 동작만 검증한다. 이벤트 모양은 kra-docs `00`의 responseExample을 따른다.
- [ ] 기존 테스트, lint, format 검사, type 검사가 모두 통과한다.
