# 05: 미국 모의 자동 매도

**What to build:** 미국 모의에서도 SL / TP가 동작한다. 켜진 SL/TP 세션 동안(뉴욕시간) 보유종목을 `FE` 체결가로 지켜보다가 트리거가 일어나면 `ust20001` 시장가로 매도 가능 수량 전량을 판다. 거래소를 모르는 종목은 지켜보지 않는다. 국내에서 만든 세션 전환, 설정 반영, 보유종목 다시 읽기, 중복 방지가 미국에도 똑같이 적용된다.

Spec: `.scratch/sl-tp-auto-sell/spec.md` (키움 TR의 미국 항목, SL / TP 실행)

**Blocked by:** 02, 03, 04

**Status:** ready-for-agent

- [x] 미국 모의 보유종목을 `ust21070`으로 읽고, 매입가는 `frgn_stk_book_uv`, 매도 가능 수량은 `sell_alowq`를 쓴다. 거래소는 종목 목록에서 찾는다.
- [x] 종목 목록에서 거래소를 찾지 못한 종목은 감시 대상에서 빼고 로그를 남긴다.
- [x] 감시 대상을 `FE`로 구독한다. `item`은 `{"jmcode": 티커, "stex_tp": ND|NY|NA}` 객체다.
- [x] 판정은 America/New_York 기준으로 켜진 세션 안이고 장구분 `290`=`0`(정규장)일 때만 한다. 프리마켓·애프터마켓·주간거래 체결은 판정하지 않는다.
- [x] 트리거가 일어나면 `ust20001`에 `trde_tp=03`, 종목 목록의 거래소로 시장가 매도가 한 번 나간다. 수량은 주문 직전 `ust21070`으로 다시 읽은 매도 가능 수량 전량이다.
- [x] 국내와 같은 경계값·중복·세션 밖·제외종목·보내기 전 취소·잘못된 체결가(0, 빈 값, 문자) 테스트를 미국 환경으로도 확인한다.
- [x] 세션 시작·끝·전환과 설정 저장 반영(제외종목 추가, 세션 OFF, 기준만 변경)을 미국 환경에서 확인한다.
- [x] `F5` 체결 이벤트와 재연결로 보유종목을 다시 읽고 구독 종목을 맞추는 동작을 미국 환경에서 확인한다.
- [x] 국내 모의와 미국 모의는 서로 다른 연결과 설정으로 따로 돌고, 한쪽의 트리거·중단이 다른 쪽에 영향을 주지 않는다.

## Comments

### 2026-10-25: 구현
- 미국 보유종목은 `ust21070`에 종목 목록(`usa10099`)의 거래소를 붙여 읽는다. 잔고 TR이 NYSE Arca ETF를 아멕스로 주는 것과 달리 종목 목록의 거래소(SPY는 NYSE)로 등록·주문한다.
- 종목 목록을 받지 못하면 보유종목 읽기 실패로 보고 다시 시도한다. 모든 종목을 거래소 불명으로 조용히 빼지 않기 위해서다. 목록에 없는 종목만 감시에서 빼고 로그에 남긴다.
- 주문 거래소는 트리거 때 읽은 값을 쓴다. 그 뒤 다시 읽어 종목이 빠져도 주문이 오류로 끝나지 않게 하기 위해서다.
- 시각은 `America/New_York`으로 바꿔 판단하므로 서머타임 전후가 자동으로 반영된다(EDT·EST 모두 테스트).
