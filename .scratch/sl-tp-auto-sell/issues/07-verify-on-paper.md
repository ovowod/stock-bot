# 07: 모의투자에서 직접 확인

**What to build:** 실제 키움 모의 서버에서 SL / TP 자동 매도가 처음부터 끝까지 동작하는지 확인하고, 문서로 확인하지 못한 키움 동작을 기록한다. 국내는 한국 장중, 미국은 한국시간 밤(뉴욕 정규장)에 사용자와 함께 확인한다. 실전 환경에서는 실행하지 않는다.

Spec: `.scratch/sl-tp-auto-sell/spec.md` (Testing Decisions의 모의투자 확인, Further Notes)

**Blocked by:** 01, 02, 03, 04, 05, 06

**Status:** ready-for-human

- [ ] 국내 모의 시장가 매도(`kt10001`, `trde_tp=3`)가 접수되고 주문번호가 온다. 확인되면 `.scratch/sell-order/issues/04-verify-sells-on-paper.md`의 남은 항목도 갱신한다.
- [ ] 모의 서버에서 `0B`(국내)와 `FE`(미국) 체결이 오는지, 대략의 빈도, 장구분 `290` 값을 기록한다.
- [ ] 한 연결에 실시간 등록을 몇 종목까지 받는지, 넘으면 어떤 응답이 오는지 기록한다(확인할 수 있는 범위에서).
- [ ] 같은 종목을 다른 가격으로 추가 매수한 뒤에도 `kt00018`의 `pur_pric`(미국은 `ust21070`의 `frgn_stk_book_uv`)가 평균 매입가로 바뀌는지 확인한다(미국은 02 첫 단계에서 평균 매입가임을 확인함. 국내는 보유종목이 없어 확인하지 못해, 국내 `pur_pric`가 `pur_amt ÷ rmnd_qty`와 같은지도 여기서 확인한다).
- [ ] 국내 모의 보유종목 1주로 기준을 현재 수익률 근처에 둔 세션을 켜고, 트리거 → 자동 매도 접수 알림 → 체결 알림("SL / TP 자동 매도" 표시)까지 이어지는지 확인한다.
- [ ] 미국 모의에서 같은 흐름을 확인한다.
- [ ] 같은 세션에서 기준을 넘은 시세가 계속 와도 주문이 한 번뿐인지 로그로 확인한다.
- [ ] 확인 결과와 새로 알게 된 키움 동작을 spec의 Further Notes와 이 파일의 Comments에 남긴다.
