# 03: 평균 매입가가 바뀌면 발생 풀고 판정 다시 시작

**What to build:** 서버가 꺼진 사이 팔고 다시 산 보유분이 재매수 이전의 데드크로스 발생이나 하향 돌파로 팔리지 않게 한다. 기억마다 평균 매입가를 두고, 보유종목을 다시 읽을 때와 주문 직전에 값이 다르면 체결을 받았든 아니든 발생을 푼다. 그 조회에서는 팔지 않고 가장 최근 완료 봉까지를 판정한 것으로 둔다. 잘못되더라도 팔지 않는 쪽으로 간다.

Spec: `.scratch/dead-cross-auto-sell/spec.md` (평균 매입가, 보내기 직전 확인, 판정 기록 파일, 로그)

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 상태와 관계없이 기억마다 평균 매입가가 판정 기록에 남고, 재시작 뒤에도 이어진다. 기억의 값이 없으면 다시 읽은 값으로 채운다.
- [ ] 보유종목을 다시 읽었을 때 값이 다르면 발생이 풀리고, 그 조회의 가장 최근 완료 봉까지가 판정된 것으로 남으며 주문이 나가지 않는다.
- [ ] 서버가 꺼진 사이 재매수한 경우를 재시작으로 재현한다. 추적 중이던 종목과 데드크로스 발생이던 종목 모두 재매수 이전의 하향 돌파로 팔리지 않는다.
- [ ] 차트 조회가 실패하면 다음 조회에서 같은 처리를 한다.
- [ ] 주문 직전에 다시 읽은 값이 다르면 발생이 풀리고 주문 TR이 나가지 않는다.
- [ ] 추가 매수로 값이 바뀌어도 같은 처리를 하며, 다음 하향 돌파 때 판다.
- [ ] 어느 쪽이든 매입가가 없으면 비교하지 않고 판다.
- [ ] `dead_cross_released`에 이유와 이전·새 평균 매입가가 남는다.
