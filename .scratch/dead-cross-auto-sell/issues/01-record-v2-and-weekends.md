# 01: 판정 기록 버전 2와 토·일 세션 제외

**What to build:** 자동 매도를 붙이기 전에 안전 조건을 먼저 끝낸다. 상태만 계산하던 때의 판정 기록을 한 번만 비워, 오래된 데드크로스 발생이 배포 뒤 매도로 이어지지 않게 한다. Dead Cross는 시세가 아니라 시계로 움직이므로 토·일에는 Dead Cross 세션이 없는 것으로 보고, 조회와 판정을 하지 않는다. 판정 기록의 버전 2 형식은 이 ticket에서 정한다. 평균 매입가와 최근 자동 매도 칸을 비어 있는 채로 두고, 값은 03과 04에서 채운다.

Spec: `.scratch/dead-cross-auto-sell/spec.md` (세션, 판정 기록 파일, 로그)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 버전 1 기록을 읽으면 기억을 모두 버리고 빈 버전 2로 다시 쓰며, `dead_cross_record_migrated`에 버린 종목코드를 남긴다.
- [x] 정리는 한 번만 일어난다. 버전 2 기록은 재시작 뒤에도 기억이 이어진다.
