# 02: 하향 돌파 자동 매도와 다시 시도

**What to build:** 국내·미국 모의의 켜진 Dead Cross 세션에서 판정을 끝낸 종목이 데드크로스 발생이면, 공용 자동 매도로 매도 가능 수량 전량을 시장가로 판다. 같은 발생 봉으로는 세션마다 한 번만 내고, 아직 보유 중이고 발생이 남아 있으면 다음 세션과 서버 재시작 뒤 첫 판정에서 다시 시도한다. 사용자는 Discord 알림, 체결 알림의 "Dead Cross 자동 매도", 계좌 확인 Dead Cross 보기의 자동 매도 칸으로 결과를 본다. 실전투자에서는 감시도 주문도 일어나지 않는다.

Spec: `.scratch/dead-cross-auto-sell/spec.md` (언제 파는가, 보내기 직전 확인, 자체 서버 API의 `auto_sell`, 화면, Discord 알림, 로그, 실전투자 차단)

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 하향 돌파 때 국내·미국 모의에서 전량 시장가 매도가 나가고, 미국은 보유종목의 거래소로 보낸다. 조회 차례는 주문 결과를 기다리지 않는다.
- [ ] 세션 밖 하향 돌파는 다음 켜진 세션에서 풀리지 않았을 때만 팔리고, 같은 판정에서 풀린 종목은 팔리지 않는다.
- [ ] 제외종목과 대상 아님 종목은 팔리지 않고, 매입가가 없는 종목은 팔린다.
- [ ] 같은 발생 봉으로는 세션마다 한 번만 내고, 기준만 바꿔 저장해도 다시 내지 않는다. 풀렸다가 다시 하향 돌파하면 같은 세션에서도 낸다.
- [ ] 기준이 바뀐 뒤 봉이 모자라 풀림을 판정하지 못했으면 내지 않는다.
- [ ] 접수, 거부, 결과 확인 불가, 매도 가능 수량 0, 다른 자동 매도 진행 중, 보내기 전 취소를 spec대로 처리한다. 같은 종목의 SL / TP 자동 매도가 진행 중이면 보내지 않는다.
- [ ] 일부 체결을 포함해 아직 보유 중이고 발생이 남아 있으면 다음 세션과 재시작 뒤 첫 판정에서 다시 시도한다. 그 전에 풀렸거나 차트 조회가 실패하면 내지 않는다.
- [ ] 키움에 보내기 직전에 감시 멈춤, 세션 변경, 같은 세션의 기준 변경, 제외종목 추가, 기억 없어짐, 풀림이면 보내지 않고 이유를 로그에 남긴다.
- [ ] 상태 API의 `stocks[].auto_sell`이 보내는 중, 접수, 실패와 이유를 담는다. 새 세션 실행에서는 `null`로 돌아간다.
- [ ] 계좌 확인 Dead Cross 보기의 상세에 자동 매도 칸이 spec의 순서대로 보이고, 좁은 화면 배지는 상태 이름만 보인다.
- [ ] 설정 화면과 계좌 확인의 "팔지 않습니다" 안내가 실제로 판다는 안내로 바뀐다.
- [ ] Discord로 접수, 실패, 결과 확인 불가만 spec의 칸으로 보낸다. 다시 시도는 표시하고, 보내지 않은 경우와 하향 돌파만으로는 보내지 않는다.
- [ ] 체결 알림에 "Dead Cross 자동 매도"가 붙고, 판정부터 체결 알림까지 같은 요청 ID로 이어진다.
- [ ] 실전 환경에서는 차트 조회와 주문 TR이 0건이다.
