# 04: 감시 상태와 최근 자동 매도 목록

**What to build:** Dead Cross 설정 화면에서 지금 감시 중인지, 멈췄다면 왜인지와 최근 자동 매도 10건을 본다. 전량 체결로 종목이 계좌 목록에서 사라져도, 서버를 다시 시작해도 결과가 남는다. 보내지 못한 시도도 목록에 남겨 왜 안 팔렸는지 알 수 있게 한다.

Spec: `.scratch/dead-cross-auto-sell/spec.md` (판정 기록 파일, 자체 서버 API의 `recent_sells`, 화면)

**Blocked by:** 02

**Status:** ready-for-agent

- [x] 주문을 보내기 전에 `sending` 항목을 저장하고 결과로 갱신해, 시각, 종목, 수량, 결과, 주문번호, 이유, 발생 봉, 다시 시도 여부가 판정 기록에 최신부터 10건까지 남는다.
- [x] 주문 응답 전에 서버가 꺼지면 재시작 때 그 항목이 `failed`, 이유 `unknown`으로 바뀐다.
- [x] 상태 API의 `recent_sells`가 최신부터 답하고, 재시작 뒤에도 남는다. 감시하지 않는 환경은 `[]`이다.
- [x] 설정 화면 안내 아래에 감시 상태 패널이 있고, "감시 중" 또는 "감시 안 함 · <이유>"와 지금 세션, 기준을 보인다.
- [x] 목록의 시각은 투자 환경의 시간대로 보이고, 오늘이 아니면 날짜를 붙인다. 다시 시도는 표시한다.
- [x] 목록이 비어 있으면 "최근 자동 매도가 없습니다"를 보인다.
- [x] 3초마다 갱신하고 탭이 숨으면 멈추며, 조회가 실패하면 마지막 값과 실패 안내를 보인다.
- [x] 다른 기능의 설정 화면은 바뀌지 않는다.
- [x] 휴대폰 폭에서 패널과 목록이 잘리지 않는다.
