# Discord 알림 모듈

조사: `research.md`

## 범위

Discord 채널로 알림을 보내는 재사용 모듈만 만든다. 주문 접수·체결 등 실제 기능에는 아직 연결하지 않는다.
이후 체결처럼 사용자가 가만히 있어도 일어나는 일을 알리는 데 쓴다.

## 결정

- 방식: Bot + REST API (`POST /channels/{id}/messages`). Gateway 연결은 하지 않는다.
- 설정: `DISCORD_BOT_TOKEN`, `DISCORD_CHANNEL_ID`. 하나라도 비어 있으면 알림만 꺼지고 앱은 정상 실행한다.
- 실패: 429면 `retry_after`만큼 기다렸다 한 번만 다시 보낸다. 그 밖의 실패는 로그만 남기고 호출한 쪽에 오류를 던지지 않는다.
- 형태: 텍스트와 embed를 둘 다 지원한다. 멘션(`@everyone` 등)은 항상 막는다.
- 길이: 텍스트는 2000자에서 자르고 끝에 `…`를 붙인다. 자른 사실을 로그에 남긴다. embed 항목도 Discord 한도에서 같은 방식으로 자른다.
- 투자 환경: 모듈이 투자 환경을 받아 `[국내 모의]` 같은 머리말을 붙인다. 투자 환경과 무관한 알림은 생략할 수 있다.
- 내용: 계좌번호, 앱 키, 토큰은 알림에 넣지 않는다. 체결 종목·수량·가격, 평가금액은 넣어도 된다.
- 실제 Discord 확인: 코드를 추가하지 않고, 사용자가 터미널 한 줄 명령으로 테스트 메시지를 보내 확인한다.

## 나중에 정할 것

- 알릴 일(체결, 거부, 취소 등)과 계좌 요약 알림 시점.
- 체결 수신 방식(키움 WebSocket `00`/`F5` 또는 REST 조회)과 실전 계좌를 들을지.
