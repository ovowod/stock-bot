# 04: 로그인 세션 만료

**What to build:** 탭을 열어 둔 채로도 로그인 세션이 끝난다. 서버는 30분 동안 요청이 없거나 로그인 후 12시간이 지나면 세션을 끝낸다. 화면은 30분 동안 입력이 없으면 요청을 기다리지 않고 바로 로그인 화면으로 바꿔 계좌 정보를 가린다.

Spec: `.scratch/password-auth/spec.md` (User Stories 11·11a, 세션, 화면)

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 서버: 마지막 요청 후 30분, 로그인 후 12시간이 지나면 다음 요청이 401 `unauthorized`이고 세션이 지워진다. 로그 `session_expired`(idle/absolute 구분).
- [ ] 서버: 만료 전의 요청은 idle 시간을 늘린다. 시계는 테스트에서 주입할 수 있다.
- [ ] 화면: 마우스·키보드·터치 입력이 30분 동안 없으면 logout을 부르고 로그인 화면과 "로그인이 만료되었습니다"를 보여준다. 토스트도 사라진다. 입력이 있으면 다시 센다.
- [ ] 백엔드 테스트: idle 29분은 유효, 30분은 401. 계속 요청해도 12시간이 지나면 401.
- [ ] e2e(시계 조작): 30분 동안 입력이 없으면 로그인 화면과 안내, 그 전에 입력하면 대시보드 유지.
- [ ] 전체 검증 명령 통과.
