# 05: 로그인 시도 제한

**What to build:** 같은 IP에서 비밀번호를 연속 5번 틀리면 그 IP는 15분 동안 로그인할 수 없다. 로그인 화면은 언제 다시 시도할 수 있는지 보여준다.

Spec: `.scratch/password-auth/spec.md` (User Stories 4, 시도 제한)

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] IP별 연속 실패 수를 메모리에 둔다. 5번째 실패에서 15분 잠근다(로그 `login_locked`). 성공하면 실패 수를 지운다.
- [ ] 잠긴 IP의 로그인은 비밀번호를 확인하지 않고 429 `login_locked`와 `retry_after_seconds`를 돌려준다(맞는 비밀번호여도). 로그 `login_rejected_locked`. 잠긴 동안의 시도는 실패 수에 넣지 않는다.
- [ ] 잠금이 풀리면 실패 수는 0부터 다시 센다. 풀린 IP의 기록은 메모리에서 지운다.
- [ ] 400 `invalid_request`는 실패 수에 넣지 않는다.
- [ ] `X-Forwarded-For`는 읽지 않는다.
- [ ] 화면: 429면 "로그인 시도가 너무 많습니다. N분 후 다시 시도하세요"가 보인다(N은 올림).
- [ ] 백엔드 테스트(시계 주입): 5번 실패 후 맞는 비밀번호도 429, 15분 뒤 다시 성공. 풀린 뒤 한 번 틀려도 잠기지 않음. 다른 IP는 영향 없음.
- [ ] e2e: 429 응답에서 남은 분이 보인다.
- [ ] 전체 검증 명령 통과.
