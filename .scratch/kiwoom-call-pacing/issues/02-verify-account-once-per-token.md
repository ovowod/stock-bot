# 02: 계좌번호 확인을 토큰마다 한 번

**What to build:** 계좌 확인이 같은 접근 토큰을 쓰는 동안에는 계좌번호 확인(`ka00001`)을 한 번만 한다. 계좌 확인, 보유 수량 확인, 매도 직전 잔고 재확인이 매번 `ka00001`을 부르지 않게 되어, 가장 자주 막히던 호출이 줄어든다.

Spec: `.scratch/kiwoom-call-pacing/spec.md` (Implementation Decisions > 계좌번호 확인을 토큰마다 한 번)

**Blocked by:** 없음

**Status:** ready-for-agent

- [x] 지금 토큰으로 `ka00001` 확인에 성공했으면, 같은 토큰을 쓰는 동안 다시 부르지 않고 확인한 계좌번호를 쓴다.
- [x] 토큰이 바뀌면(만료 재발급, `8005` 뒤 재발급) 다시 확인한다.
