# 미국 미체결 주문 목록과 주문 취소 (모의투자)

Status: ready-for-agent

## Problem Statement

국내 계좌 확인에는 미체결 주문 목록과 주문 취소가 생겼지만(`.scratch/cancel-order/`), 미국 투자 환경의 계좌 확인에는 아직 없다. 미국 주식은 한국 시간 밤에 거래되므로, 걸어 둔 지정가 주문이 남아 있는지 보거나 거둬들이려면 키움 앱(영웅문 Global)을 따로 열어야 한다. 모의투자에서 미국 매수·매도를 연습하는 흐름도 대시보드 안에서 끝나지 않는다.

## Solution

미국 투자 환경의 계좌 확인 맨 아래에도 **미체결 주문** 패널을 둔다. 국내와 같은 화면, 같은 규칙을 쓰되 미국 TR의 차이를 반영한다.

- **주문 취소**는 남은 수량 전부만 할 수 있다. 미국 취소 TR에는 취소 수량 칸이 없다.
- 취소에 필요한 **거래소**(NYSE·NASDAQ·AMEX)는 미체결 응답에 없다. 그래서 순위·검색·보유종목처럼 **종목 목록**에서 티커로 찾는다. 찾지 못한 주문은 취소 버튼 없이 표시만 한다.
- 예약주문은 다른 TR로 취소해야 하므로 표시만 한다.

국내와 같이 **모의투자**에서만 취소할 수 있고, **실전투자**에서는 목록만 보여준다. 취소가 접수되면 토스트를 띄우고, 계좌와 목록을 다시 불러오고, Discord로 **알림**을 보낸다.

## User Stories

**미체결 목록 보기**

1. As a 투자자, I want 미국 계좌 확인 맨 아래에 미체결 주문 목록이 보이기를, so that 국내처럼 계좌와 걸어 둔 주문을 함께 본다.
2. As a 투자자, I want 키움 앱에서 낸 미국 주문도 목록에 나오기를, so that 그 계좌의 미체결 주문을 빠짐없이 본다.
3. As a 투자자, I want 주문마다 종목명과 티커가 보이기를, so that 어느 종목의 주문인지 안다.
4. As a 투자자, I want 종목명이 보유종목·순위·검색과 같은 이름으로 보이기를(종목 목록 기준), so that 화면마다 이름이 다르지 않다.
5. As a 투자자, I want 매수·매도가 색으로 구분되고, 정정 주문은 "정정"이 붙어 보이기를, so that 어떤 주문인지 바로 안다.
6. As a 투자자, I want 주문 유형이 키움 이름(지정가, 시장가, LOC 등) 그대로 보이기를, so that 어떤 방식으로 건 주문인지 안다.
7. As a 투자자, I want 주문가격이 USD로 보유종목과 같은 자릿수(소수 넷째 자리까지)로 보이고, 가격이 없는 주문은 주문 유형만 보이기를, so that 의미 없는 $0을 보지 않는다.
8. As a 투자자, I want "미체결 3 / 주문 5주"처럼 남은 수량과 주문 수량이 함께 보이기를, so that 일부 체결된 주문을 알아본다.
9. As a 투자자, I want 주문 시각이 한국 시간으로 보이기를, so that 언제 건 주문인지 안다.
10. As a 투자자, I want 거래소(NYSE·NASDAQ·AMEX)가 보이기를, so that 어디로 나간 주문인지 안다.
11. As a 투자자, I want 키움에 접수된 취소 주문 자체는 목록에 나오지 않기를, so that 거둬들일 수 없는 줄을 보지 않는다.
12. As a 투자자, I want 미체결이 없으면 "미체결 주문이 없습니다", 불러오는 동안 로딩 모양, 실패하면 패널에만 오류와 "다시 시도"가 보이기를(국내와 같음), so that 계좌 정보는 그대로 본다.
13. As a 투자자, I want 상단 새로고침·매도 접수·취소 접수 때 계좌와 미체결 목록이 함께 다시 불러와지기를(국내와 같음), so that 한 번에 최신 상태를 본다.
14. As a 투자자, I want 종목 목록을 받지 못해도 미체결 목록은 보이기를, so that 목록 문제로 걸어 둔 주문을 못 보는 일이 없다.

**취소할 수 없는 주문**

15. As a 투자자, I want 종목 목록에서 거래소를 찾지 못한 주문에는 "거래소 확인 불가" 표시와 "키움 앱에서 취소하세요" 안내만 있기를, so that 잘못된 거래소로 취소가 나가지 않는다.
16. As a 투자자, I want 예약주문에는 "예약 주문" 표시와 안내만 있기를, so that 다른 방식으로 취소해야 하는 주문을 잘못 다루지 않는다.
17. As a 투자자, I want 실전투자에서는 목록만 보이고 "실전투자에서는 주문 취소를 할 수 없습니다" 안내가 한 번 보이기를(국내와 같음), so that 실제 주문이 앱에서 취소되지 않는다.

**최종 확인과 보내기**

18. As a 투자자, I want 취소 버튼을 누르면 최종 확인이 열리고 미체결을 다시 조회해 최신 상태를 보여주기를(국내와 같음), so that 그사이 체결된 것을 반영해 판단한다.
19. As a 투자자, I want 최종 확인에 투자 환경, 매수·매도, 종목, 티커, 거래소, 주문 유형, 주문가격(USD), 주문 수량, 원주문번호, 최신 미체결 수량이 보이기를, so that 어느 주문을 취소하는지 확실히 안다.
20. As a 투자자, I want 미국 주문은 취소 수량 칸 없이 "취소 수량: 남은 수량 전부"로 보이기를, so that 일부 취소가 안 된다는 것을 안다.
21. As a 투자자, I want 다시 조회했더니 주문이 없거나, 조회가 실패하거나, 취소할 수 없는 주문이 됐으면 국내와 같은 안내와 함께 "주문 취소하기"가 막히기를, so that 확인 없이 보내지 않는다.
22. As a 투자자, I want 연타·보내는 중 닫기·결과를 알 수 없을 때의 처리가 국내와 같기를, so that 중복 취소가 나가지 않고 키움에서 먼저 확인한다.
23. As a 투자자, I want 접수되면 "주문 취소가 접수되었습니다" 토스트와 새 주문번호가 보이고 계좌와 목록이 다시 불러와지기를, so that 바뀐 상태를 바로 본다.

**Discord 알림**

24. As a 투자자, I want 미국 주문 취소가 접수되면 국내와 같은 "주문 취소 접수" 알림이 오고, 종목은 "엔비디아 (NVDA)"처럼 보이기를, so that 시장에 상관없이 같은 알림을 받는다.

**기록**

25. As a 개발자, I want 미국 미체결 조회, 거래소 찾기 실패, 취소 요청·재확인·차단·접수·거부·확인 불가가 주문 키·원주문번호와 함께 로그에 남기를, so that 로그만으로 흐름을 따라간다.

## Implementation Decisions

**미체결 주문 조회 (서버)**

- 기존 `GET /api/environments/{environment}/open-orders`가 미국 투자 환경도 받는다. 지금은 미국을 400으로 거부하는데, 이 동작을 바꾼다.
- 키움 `ust21050`(미국주식 원장 미체결, `/api/us/acnt`)을 체결 알림과 같은 본문으로 부른다: `ord_dt` 빈 값(오늘), `slby_tp=0`, `stex_tp` 빈 값, `stk_cd` 빈 값. 연속조회는 기존 키움 클라이언트가 최대 10페이지까지 이어 받는다.
- `ord_cntr_tp=12`(취소주문) 줄은 빼고 원주문(10)과 정정주문(11)만 돌려준다.
- 거래소와 이름은 종목 목록에서 티커로 찾는다(보유종목과 같은 방식). 종목 목록을 받지 못하거나 티커가 없으면, 이름은 `frgn_stk_nm`을 쓰고 거래소는 `null`로 둔다. 목록 조회는 실패시키지 않는다.
- 주문 한 건의 응답 모양은 국내와 같다. 미국에서 달라지는 값은 다음과 같다.
  - `order_no`: `ord_no`(9자리), `code`: 티커
  - `side`: `slby_tp` 1→sell, 2→buy. `side_label`: `slby_tp_nm`이고, 정정주문이면 뒤에 "정정"을 붙인다(매수정정·매도정정, 국내 표기와 맞춤).
  - `order_type`: `frgn_trde_nm` 그대로
  - `price`: `ord_uv`(USD, 소수). 0이면 `null`
  - `ordered_quantity`: `ord_qty`, `remaining_quantity`: `ord_remnq`
  - `time`: `ord_time`(이미 HH:mm:ss, KST)
  - `exchange`: 종목 목록의 거래소(NYSE·NASDAQ·AMEX) 또는 `null`
  - `blocked_reason`: `real` | `reserved` | `exchange` | `null`. 실전투자면 `real`, 예약주문(`rsrv_tp`가 "예약" 또는 "1")이면 `reserved`, 거래소가 `null`이면 `exchange`다. 이 순서로 하나만 준다.
- 필수 칸(주문번호·티커·미체결 수량)이 비었거나 숫자가 아니면 응답 형식 오류다. 가격·주문 수량이 깨졌으면 국내와 같이 그 칸만 비운다.

**주문 취소 (서버)**

- 기존 `POST /api/environments/{environment}/cancellations`가 미국 투자 환경도 받는다. 본문은 국내와 같다(`order_key`, `order_no`, `quantity`). 지금은 미국을 400으로 거부하는데, 이 동작을 바꾼다.
- 처리 순서는 국내와 같다: 실전 403 → 입력 검사 → 주문 키 중복(매수·매도·국내 취소와 같은 저장소) → 원주문번호별 잠금 → `ust21050` 재조회.
- 미국 입력 검사: 원주문번호는 1~9자리 숫자다.
- 미국은 일부 취소를 하지 않는다. 요청 수량이 재조회한 미체결 수량보다 많으면 400 `cancel_quantity_exceeded`, 적으면 400 `partial_cancel_unsupported`("미국 주문은 남은 수량 전부만 취소할 수 있습니다.")이고 키움에 보내지 않는다.
- `blocked_reason`이 있으면 400 `cancel_not_supported`이다(국내와 같음).
- 키움 `ust20003`(미국주식 취소 주문, `/api/us/ordr`)을 재시도 없이 한 번만 부른다. 본문은 `orig_ord_no`, `stex_tp`(거래소를 NA·ND·NY로 바꾼 값, 매수·매도 주문과 같은 표), `stk_cd`(재조회에서 찾은 티커)다.
- 결과 분류는 국내·매수·매도와 같다. `ord_no`가 없으면 확인 불가다. 접수 응답의 `cancel_quantity`는 `cncl_ord_qty`를 정수로 바꾼 값이고, 0이거나 읽지 못하면 `null`이다.
- 취소 접수 콜백(Discord 알림)은 국내와 같이 부른다.

**화면**

- 미체결 패널을 국내·미국 모두에 그린다. 미국은 금액을 USD(보유종목과 같은 `formatForeign` 4자리)로 표시한다.
- 취소할 수 없는 이유 배지: `reserved` → "예약 주문", `exchange` → 미국은 "거래소 확인 불가"(국내는 지금처럼 "NXT 주문"·"통합 주문").
- 미국의 최종 확인에는 취소 수량 칸과 "전부" 버튼이 없다. 대신 "취소 수량: 남은 수량 전부" 줄을 보여주고, 보내는 `quantity`는 재조회한 미체결 수량이다.
- 그 밖의 최종 확인 동작(재조회, 잠금, 새 키, 확인 불가 때 닫고 다시 불러오기)은 국내와 같다.

**Discord 알림**

- 국내와 같은 "주문 취소 접수" embed를 쓴다. 종목은 "이름 (티커)"다.

## Testing Decisions

- 좋은 테스트는 바깥에서 보이는 동작만 검증한다. 서버는 자체 API의 요청·응답과, 가짜 키움·가짜 Discord에 실제로 나간 요청을 본다. 화면은 사용자가 보는 것을 본다. 키움 서버와 Discord는 호출하지 않는다.
- 테스트 경계는 국내 미체결·취소와 같은 두 곳이다. 새 경계를 만들지 않는다.

**서버 API (pytest + 가짜 키움 + 가짜 Discord, 국내 open-orders·cancellations 테스트와 같은 방식)**

- 미국 open-orders: 문서 예제 모양의 `ust21050`이 위 응답 모양으로 바뀐다. 요청 본문과 모의 도메인을 확인하고, 종목 목록(가짜 종목 목록 TR)에서 이름·거래소를 찾는지 본다.
- 취소주문(12) 줄은 빠지고, 정정주문(11)은 "매수정정"처럼 보인다.
- 종목 목록에 없는 티커와 종목 목록 조회 실패는 `exchange`·`blocked_reason=exchange`이고, 목록은 200이다. 예약주문은 `reserved`, 실전은 `real`이다.
- 미국 취소: `ust21050` 재조회 뒤 `ust20003`이 `orig_ord_no`·`stex_tp`(NA·ND·NY)·`stk_cd`로 한 번 나간다. 수량이 적으면 400 `partial_cancel_unsupported`, 많으면 400 `cancel_quantity_exceeded`이고 `ust20003` 요청이 없다.
- 실전 403(키움 요청 없음), 입력 오류 400(10자리 주문번호 포함), 중복 409, 재조회 실패 502, 확인 불가 502, 취소 수량 `null` 규칙, 접수 알림을 국내와 같은 방식으로 검증한다.
- 지금 있는 "미국 open-orders는 400", "미국 취소는 400" 테스트는 새 동작에 맞게 바꾼다.

**화면 (Playwright e2e + 가짜 `/api` 응답, 국내 open-orders e2e와 같은 방식)**

- 미국 모의 계좌 확인에 미체결 패널이 보이고, USD 가격·티커·거래소가 보인다.
- "예약 주문"·"거래소 확인 불가" 줄에는 안내만 있고 취소 버튼이 없다. 미국 실전은 안내가 한 번 보인다.
- 미국 최종 확인에는 수량 칸이 없고 "남은 수량 전부"가 보이며, 요청 `quantity`는 재조회한 미체결 수량이다.
- 접수·거부·확인 불가의 화면 처리가 국내와 같다(대표 경우만 검증).
- 지금 있는 "미국 계좌 확인에는 패널이 없다" e2e는 새 동작에 맞게 바꾼다.
- 모바일 폭에서 가로 스크롤이 생기지 않는다.

## Out of Scope

- 미국 실전투자 주문 취소.
- 미국 일부 수량 취소(TR에 수량 칸이 없다).
- 정정 주문(`ust20002`).

## Further Notes

- 모의투자에서 미국 장중(한국 시간 밤)에 직접 확인할 것. 실전 도메인으로 나가지 않는 것을 먼저 확인한다.
  - `ord_dt` 빈 값의 "오늘"이 한국 날짜인지 미국 날짜인지. 한국 자정을 넘기면 전날 밤에 낸 주문이 목록에서 빠지는지(빠지면 체결 알림의 미체결 목록도 같은 문제가 있다).
  - 정정주문(11) 줄을 취소할 때 `orig_ord_no`에 그 줄의 `ord_no`를 넣으면 되는지.
  - `rsrv_tp` 실제 값. 문서는 "0:일반,1:예약", 예제는 "일반"이다.
  - NYSE Arca ETF(EWZ 등)의 취소가 종목 목록 기준 거래소(NY)로 접수되는지. 매도는 NY로 접수됐다(`.scratch/sell-order/spec.md`).
  - 응답 `cncl_ord_qty`가 실제 취소 수량인지, 취소 직후 목록에 주문이 남는지.
- 문서로 확인하지 못한 것: 원주문번호 자리수가 늘 9자리인지(요청 길이 9), 취소 TR의 호출 한도.
